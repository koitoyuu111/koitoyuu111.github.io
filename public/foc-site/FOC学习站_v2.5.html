FOC 学习站

磁场定向控制（Field-Oriented Control）是现代电机控制的基石。本站用可视化动画 + 数学推导 + 底层分析 + 代码实战四位一体的方式，带你从「为什么」一路走到「怎么写」。

为什么需要 FOC？

想象你在骑一辆双人自行车，但你的搭档（电机转子）一直在转圈。你踩下去的力（电流）只有垂直于他与你的连线方向的分量才能产生推进力（转矩），其余分量只是在把他往你身上推或拉开（无用甚至有害）。

FOC 做的事就是：实时算出搭档此刻转到哪个角度，然后精准地只踩"垂直方向"那一脚。在电机里：

  • d 轴（直轴）：沿着转子磁场方向 —— 控制磁链（励磁）
  • q 轴（交轴）：垂直于转子磁场方向 —— 控制转矩

把三相交流电"变换"到跟随转子旋转的 dq 坐标系后，交流量就变成了直流量，于是可以用最经典的 PI 控制器分别精准控制励磁和转矩。这就是 FOC 的核心思想。

第 1 章 · 电机与磁场的直觉

1.1 视觉理解：三相电流如何合成旋转磁场

三相定子绕组在空间上互差 120°。当通入相位互差 120° 的三相正弦电流时，每相产生的磁场矢量叠加起来，会合成一个幅值恒定、匀速旋转的合成磁场。下面左侧是三相电流波形（拖动时间滑块），右侧是此刻的空间矢量合成。

图 1-1：左图为三相电流 $i_a,i_b,i_c$（相位互差 120°）；右图为对应的空间电流矢量合成。注意合成矢量（白色箭头）幅值恒定、以电角速度匀速旋转。

1.2 底层分析：三相绕组与磁动势

设三相绕组轴线分别为 $a,b,c$（空间互差 $\frac{2\pi}{3}$），每相匝数 $N$，通入电流：

$$i_a = I_m\cos(\omega t),\quad i_b = I_m\cos(\omega t - \tfrac{2\pi}{3}),\quad i_c = I_m\cos(\omega t + \tfrac{2\pi}{3})$$

每相产生的磁动势（MMF）是沿该相轴线方向的脉振矢量。把三相 MMF 用空间矢量表示并叠加（这里先直觉理解，严格推导见第 2 章），合成磁动势为：

$$\vec{F} = \tfrac{3}{2} N I_m \, e^{j\omega t}$$

这是一个幅值为 $\frac{3}{2}NI_m$、以角速度 $\omega$ 匀速旋转的矢量。这就是"旋转磁场"。

1.3 底层分析：转矩从哪来

转子（永磁体）有自己的磁场 $\vec{\psi}_r$。定子旋转磁场 $\vec{F}$ 与转子磁场之间的夹角 $\delta$（称为转矩角 / 功角）决定了电磁转矩：

$$T_e = \tfrac{3}{2} p \, \psi_r \, i_s \sin\delta$$

其中 $p$ 为极对数，$i_s$ 为定子电流幅值。关键结论：

  • $\delta = 90°$ 时转矩最大 —— 定子磁场"领先"转子 90° 时最省力
  • $\delta = 0$ 时转矩为零 —— 两磁场对齐，只有径向拉力
  • 传统方波控制（BLDC 六步换相）中 $\delta$ 在 60°~120° 之间跳动，产生转矩脉动
FOC 的目标就是：始终保持 $\delta = 90°$，让每一分电流都用来产生转矩。

1.5 面试视角：电机类型与基本参数

做电机控制之前，先搞清楚控制对象是什么。面试里“BLDC 和 PMSM 有什么区别”几乎是必问题。

  • BLDC（无刷直流电机）：反电动势是梯形波，通常用方波（六步换相）驱动，控制简单、成本低，但转矩脉动大、有换相噪声（见 1.4 的对比动画）。
  • PMSM（永磁同步电机）：反电动势是正弦波，适合正弦电流驱动的 FOC，转矩平稳、噪声小，是伺服/新能源车/家电高端方案的主流。
  • 表贴式 SPM：磁钢贴在转子表面，$L_d \approx L_q$，转矩只有永磁转矩一项，$i_d=0$ 控制即最优。
  • 内嵌式 IPM：磁钢埋在转子内部，$L_d < L_q$，除了永磁转矩还有磁阻转矩。最优电流方向不再是纯 q 轴，需要 MTPA（最大转矩电流比）分配 $i_d,i_q$，同转矩下电流更小、效率更高。

极对数 $p$ 是另一个必背参数：电角度 = $p$ × 机械角，电角速度 $\omega_e = p\,\omega_m$。极对数多 → 同机械转速下电频率高、同电流下转矩大，但最高转速受限（反电动势随 $\omega_e$ 增长）；编码器每转线数折算到电角度时也要除以 $p$，这是调试时常见的坑。

Q：BLDC 和 PMSM 的本质区别？
反电动势波形不同（梯形 vs 正弦），决定了驱动方式：BLDC 用方波六步换相，PMSM 用正弦 FOC。硬件结构上 PMSM 的绕组分布也更接近正弦磁场。
Q：极对数如何影响控制？
电角度 = p × 机械角。极对数越大，同转速下电频率越高、转矩密度越大，但反电动势限压更早、对角度分辨率要求更高（同样编码器线数下电角度分辨率变粗 p 倍）。
Q：IPM 电机为什么要做 MTPA？
因为 $L_d < L_q$，转矩含磁阻分量 $\tfrac{3}{2}p(L_d-L_q)i_d i_q$，把部分电流分到 $i_d$（负值）可以用更小的总电流产生同样转矩；SPM 电机 $L_d=L_q$，MTPA 退化为 $i_d=0$。

1.6 代码举例：合成旋转磁场（C）

下面的 C 函数就是图 1-1 背后的核心计算，把三相电流合成 αβ 平面上的矢量（这正是 Clarke 变换，详见第 2 章）：

#include <math.h>
#include <stdio.h>
#define SQRT3 1.7320508075688772f
#define PI    3.1415926535897932f

typedef struct { float alpha, beta; } ab_t;

/* 等幅值 Clarke 变换：三相 → αβ 平面矢量 */
ab_t clarke(float ia, float ib, float ic) {
    ab_t v;
    v.alpha = ia;
    v.beta  = (ib - ic) / SQRT3;
    return v;
}

/* t 秒时刻的三相对称电流（幅值 Im，角频率 omega） */
void three_phase(float t, float Im, float omega,
                 float* ia, float* ib, float* ic) {
    *ia = Im * cosf(omega * t);
    *ib = Im * cosf(omega * t - 2.0f * PI / 3.0f);
    *ic = Im * cosf(omega * t + 2.0f * PI / 3.0f);
}

int main(void) {
    /* 无论 t 取何值，合成矢量幅值恒等于 Im，角度随时间线性增长 */
    for (float t = 0.0f; t < 0.02f; t += 0.005f) {
        float ia, ib, ic;
        three_phase(t, 1.0f, 2.0f * PI * 50.0f, &ia, &ib, &ic);
        ab_t v = clarke(ia, ib, ic);
        float mag = sqrtf(v.alpha * v.alpha + v.beta * v.beta);
        float ang = atan2f(v.beta, v.alpha);
        printf("t=%.3fs  幅值=%.4f  角度=%.2f rad\n", t, mag, ang);
    }
    return 0;
}

运行后你会发现：无论 t 取何值，输出幅值恒等于 $I_m=1.0$，角度随时间线性增长 —— 这就是旋转磁场。

第 2 章 · Clarke 变换

2.1 为什么需要坐标变换

三相电流 $i_a,i_b,i_c$ 是三个随时间正弦变化的量，但它们并不独立：对绕组星型连接且中点不引出，有

$$i_a + i_b + i_c = 0$$

三个相关变量描述一个二维物理量（平面上的电流矢量）是冗余的。Clarke 变换把三相量投影到静止的 αβ 两相正交坐标系，消去冗余，把问题从三维降到二维。

2.2 理论推导：从三相到 αβ

取 α 轴与 a 相绕组轴线重合，β 轴超前 α 轴 90°。把三相磁动势矢量向 α、β 轴投影。设等效两相绕组匝数为 $N_2$，三相为 $N_3$，并令变换前后磁动势不变：

$$ \begin{aligned} N_2 i_\alpha &= N_3\left(i_a - i_b\cos\tfrac{\pi}{3} - i_c\cos\tfrac{\pi}{3}\right)\\ N_2 i_\beta &= N_3\left(0 + i_b\sin\tfrac{\pi}{3} - i_c\sin\tfrac{\pi}{3}\right) \end{aligned} $$

代入 $i_c = -i_a - i_b$ 并化简，得到等幅值（amplitude-invariant）Clarke 变换：

$$ \boxed{ \begin{aligned} i_\alpha &= i_a\\ i_\beta &= \dfrac{i_b - i_c}{\sqrt{3}} = \dfrac{i_a + 2i_b}{\sqrt{3}} \end{aligned}} $$

写成矩阵形式（含零序分量 $i_0$，对称三相时为零）：

$$ \begin{bmatrix} i_\alpha \\ i_\beta \\ i_0 \end{bmatrix} = \frac{2}{3} \begin{bmatrix} 1 & -\tfrac12 & -\tfrac12\\ 0 & \tfrac{\sqrt3}{2} & -\tfrac{\sqrt3}{2}\\ \tfrac12 & \tfrac12 & \tfrac12 \end{bmatrix} \begin{bmatrix} i_a \\ i_b \\ i_c \end{bmatrix} $$
等幅值 vs 等功率：等幅值变换保证 $|\vec i_{\alpha\beta}| = |\vec i_{abc}|$，在电机控制中最常用（SimpleFOC、TI InstaSPIN 都用它）；等功率变换则保持功率不变，多见于电网分析。本站统一用等幅值形式。

2.4 底层分析：物理意义与工程细节

  • 降维：3 个相关变量 → 2 个独立变量，后续所有运算（Park、PI、SVPWM）都在二维平面进行。
  • 仍是交流：αβ 分量仍是正弦交流量（互差 90°），所以不能直接用 PI 无静差跟踪 —— 这正是下一章 Park 变换要解决的。
  • 硬件实现：实际 MCU 通常只采样两相电流（$i_a,i_b$），第三相由 $i_c=-i_a-i_b$ 算出，节省一路 ADC。因此工程代码里常写成 $i_\beta = (i_a + 2i_b)/\sqrt3$。

2.5 面试视角：电流采样工程细节

Clarke 变换的输入是三相电流的瞬时采样值，采得准不准直接决定控制质量。两个高频考点：

  • 什么时候采？三相电流应在 PWM 有效矢量作用的中段采样：此时电流稳定、离开关瞬态最远，开关噪声最小。中心对齐 PWM 的谷底/峰顶时刻正好对应两个有效矢量中心，因此工程上普遍用定时器比较事件硬件触发 ADC。
  • 怎么采？
    • 两/三电阻低侧采样：每相下管串采样电阻，只在下管导通时能测到该相电流，需要配合 PWM 时序选窗口，成本最低、最常用。
    • 母线单电阻采样：只在直流母线上放一个电阻，靠两个有效矢量时刻的母线电流重构出两相电流；成本最低但可观测窗口受限（两相占空比接近时重构失效，需要移相补偿）。
    • 高端方案用隔离运放/Σ-Δ 调制器或电流传感器，任意时刻可采。
  • 偏置校准：上电时电机未转，先采若干点求平均作为零点偏置扣除，否则 $i_\alpha,i_\beta$ 带直流偏置，表现为转矩脉动。
Q：三相电流什么时候采样？为什么？
在有效电压矢量作用的中段采样：此时相电流基本恒定（电感上电流变化慢），且离开关管的噪声瞬态最远。一般用 PWM 定时器比较事件硬件触发 ADC，保证采样时刻与开关时序严格同步。
Q：单电阻采样为什么有时会采不到电流？
母线电流只在有有效矢量输出时等于某一相电流；当两相占空比太接近（或接近零矢量）时，采样窗口太短甚至不存在，无法重构两相电流。工程上通过移相/拉宽最小有效矢量时间来保证观测窗口。

2.6 代码举例

C（嵌入式常用，只采两相电流）：

#include 
#define SQRT3 1.7320508075688772f

typedef struct { float alpha, beta; } ab_t;

// 等幅值 Clarke 变换（只用 ia, ib 两路采样）
ab_t clarke_transform(float ia, float ib) {
    ab_t out;
    out.alpha = ia;
    out.beta  = (ia + 2.0f * ib) / SQRT3;  // 等价于 (ib - ic)/√3
    return out;
}

逆变换与零序分量（验证用，C）：

// 完整 Clarke（含零序分量 i0，对称三相时 i0=0）
void clarke_full(float ia, float ib, float ic,
                 float* alpha, float* beta, float* i0) {
    *alpha = ia;
    *beta  = (ib - ic) / SQRT3;
    *i0    = (ia + ib + ic) / 3.0f;
}

// Clarke 逆变换：αβ → 三相
void clarke_inv(float alpha, float beta,
                float* ia, float* ib, float* ic) {
    *ia = alpha;
    *ib = -alpha / 2.0f + SQRT3 * beta / 2.0f;
    *ic = -alpha / 2.0f - SQRT3 * beta / 2.0f;
}

第 3 章 · Park 变换与 dq 轴

3.1 核心思想：站到转子上去看

Clarke 变换把三相变成二维，但 αβ 仍是交流正弦量。如果我们建立一个随转子同步旋转的坐标系 dq（d 轴对准转子磁链方向），那么站在 dq 系上看，原本旋转的电流矢量就变成了相对静止的直流量。直流量意味着：用普通 PI 控制器就能实现无静差跟踪。这是 Park 变换的全部意义。

3.2 理论推导

设转子电角度为 $\theta_e$，则 dq 系相对静止 αβ 系旋转了 $\theta_e$。把 αβ 矢量向旋转的 d、q 轴投影（逆时针为正，q 轴超前 d 轴 90°）：

$$ \boxed{ \begin{aligned} i_d &= i_\alpha\cos\theta_e + i_\beta\sin\theta_e\\ i_q &= -i_\alpha\sin\theta_e + i_\beta\cos\theta_e \end{aligned}} $$

矩阵形式：

$$ \begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix} $$

逆变换（把控制输出的 $u_d,u_q$ 变回 $u_\alpha,u_\beta$ 去驱动 SVPWM）：

$$ \begin{bmatrix} u_\alpha \\ u_\beta \end{bmatrix} = \begin{bmatrix} \cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} u_d \\ u_q \end{bmatrix} $$

3.3 视觉理解：同一个矢量在两个坐标系下的读数

下面动画中，电流矢量（白色）在 αβ 系中匀速旋转。绿色坐标系是随矢量同步旋转的 dq 系。观察：αβ 读数是正弦波，而 dq 读数几乎是常数。可以让 dq 系"失锁"（转速与矢量不同步），直观看到交流分量又回来了。

图 3-1：左：αβ（灰，静止）与 dq（绿，旋转）坐标系下的同一电流矢量；右：四个分量随时间的波形。当 dq 系转速=100%（与矢量同步）时，$i_d,i_q$ 为常数；失步时恢复为交流。

3.4 底层分析：d 轴和 q 轴分别控制什么

  • $i_q$（交轴电流）：与转子磁链垂直，直接产生电磁转矩。$T_e = \frac{3}{2}p\psi_r i_q$（表贴式 PMSM）。想要多大转矩，就给多大 $i_q$ 指令。
  • $i_d$（直轴电流）：与转子磁链同向，不产生转矩（对表贴式电机），只起增磁/弱磁作用。正常运行令 $i_d=0$（$i_d=0$ 控制），高速弱磁区才让 $i_d<0$。

这就是"解耦"：原本耦合在一起的三相交流，被拆成两个可以独立 PI 调节的直流量 —— 一个管转矩（$i_q$），一个管磁场（$i_d$）。这正是直流电机里"励磁电流"和"电枢电流"的关系，FOC 因此也叫"按转子磁场定向的控制"，让交流电机拥有了直流电机般的控制性能。

3.5 面试视角：角度从哪来

Park 变换的灵魂是 $\theta_e$。FOC 的全部性能都建立在“角度准”这一个前提上，所以角度获取是面试必考话题。

  • 增量编码器（ABZ）：靠计数脉冲得相对位置，上电需回零/对齐；分辨率 = 线数 × 4（四倍频）再除以极对数得电角度分辨率。
  • 绝对编码器（SSI/BiSS/多圈）：上电即知绝对位置，免回零，伺服标配。
  • 霍尔传感器：只给 6 个 60° 粗位置，可插值估算电角度，成本低、精度有限。
  • 无感观测器：中高速用滑模观测器（SMO）或磁链观测器反推反电动势角度；零低速反电动势为零，只能靠高频注入（HFI）利用凸极性（$L_d \neq L_q$）提取位置（详见第 6 章）。

角度偏差 offset：机械安装或信号延时会让实际角度带一个常数偏差 $\theta_{off}$。后果是 dq 解耦错位：给定 $i_q$ 实际混入 d 轴分量，表现为转矩变小、电流变大、高速时母线电流异常。常用标定：拖到恒速后微调 $\theta_{off}$ 使同 $i_q$ 下电流最小（或高频注入法/对拖法）。

弱磁控制：反电动势 $\omega_e\psi_r$ 随转速升高，当它逼近母线电压能提供的极限时，电流就推不进去了。约束有两个：

$$i_d^2 + i_q^2 \le I_{\max}^2,\qquad u_d^2 + u_q^2 \le U_{\max}^2$$

在 $i_d$-$i_q$ 平面上分别是电流极限圆和随转速变小的电压极限椭圆。弱磁就是高速时主动给 $i_d<0$，用去磁作用压低反电动势，让电压矢量回到椭圆内，代价是同电流下转矩变小。新能源车“基速以下恒转矩、基速以上恒功率”的特性就是这么来的。

Q：FOC 为什么必须知道准确的转子角度？
Park 变换要用 $\theta_e$ 把交流量投影到跟随转子的 dq 系；角度错了，dq 轴就不再对准转子磁场，$i_d,i_q$ 解耦失效，电流环越努力反而转矩越不对。
Q：角度存在固定偏差会怎样？怎么标？
dq 坐标旋转了一个偏角，给定 $i_q$ 混入去磁/增磁分量：转矩降低、同转矩电流增大、高速弱磁区异常。标定方法：恒速拖拽下扫描 $\theta_{off}$，找同 $i_q$ 指令下电流最小（或转矩最大）的点。
Q：讲讲弱磁的原理。
高速时反电动势逼近电压极限（椭圆约束），注入负 $i_d$ 削弱气隙磁链、压低反电动势，使电压矢量重新落在椭圆内，从而拓展转速范围；代价是转矩能力下降，进入恒功率区。

3.6 代码举例

C（嵌入式）：

typedef struct { float d, q; } dq_t;

// Park 变换：αβ(静止) → dq(旋转)，theta 为电角度
dq_t park_transform(float alpha, float beta, float theta) {
    float c = cosf(theta), s = sinf(theta);
    dq_t out;
    out.d =  alpha * c + beta * s;
    out.q = -alpha * s + beta * c;
    return out;
}

// 反 Park 变换：dq → αβ（用于把 PI 输出送回 SVPWM）
void park_inv(float d, float q, float theta, float* alpha, float* beta) {
    float c = cosf(theta), s = sinf(theta);
    *alpha = d * c - q * s;
    *beta  = d * s + q * c;
}

完整 Clarke+Park 链路验证（C，可编译运行）：

#include <math.h>
#include <stdio.h>
#define SQRT3 1.7320508075688772f
#define PI    3.1415926535897932f

int main(void) {
    /* 模拟：三相对称电流，ωt = θ（同步旋转） */
    float t = 0.013f, Im = 2.0f, w = 2.0f * PI * 50.0f;
    float ia = Im * cosf(w * t);
    float ib = Im * cosf(w * t - 2.0f * PI / 3.0f);
    float ic = Im * cosf(w * t + 2.0f * PI / 3.0f);

    /* Clarke */
    float alpha = ia;
    float beta  = (ib - ic) / SQRT3;
    /* Park（θ = ωt，与电流矢量同步） */
    float th = w * t, c = cosf(th), s = sinf(th);
    float d =  alpha * c + beta * s;
    float q = -alpha * s + beta * c;

    printf("id = %.4f\n", d);  /* ≈ 2.0000（常数） */
    printf("iq = %.4f\n", q);  /* ≈ 0.0000（常数） */
    return 0;
}

第 4 章 · SVPWM：用 8 个开关变出任意电压

先搞清楚这一章要干什么。
上一章末尾，反 Park 变换吐出两个数 $u_\alpha, u_\beta$。翻译成人话就一句：「现在请朝 $\theta$ 这个方向、加一个大小 $U$ 的电压」。

可我手上只有一块电池（直流母线 $U_{dc}$）和 6 个开关管。开关只有「通」和「断」，没有中间档。

这一章要解决的就是这一件事：用一堆只会「通 / 断」的开关，凑出任意方向、任意大小的电压。

没接触过 PWM 也完全没关系 —— 我们从台灯调光讲起，全程不用背公式。

4.1 第 0 步：开关只有两档，怎么变出「中间电压」？

一个开关只有两种状态：接通，电压是 $U_{dc}$；断开，电压是 0。中间值是不存在的。

但如果我以每秒两万次的速度疯狂开关，其中 30% 的时间接通呢？

电机绕组是一个很大的电感。电感里的电流不能突变，它「看不清」这么快的跳动，只对平均效果有反应。就像一个转得飞快的风扇，你看不见扇叶，只感觉到一阵连续的风。

$$U_{平均} = D \times U_{dc}\qquad (D = 占空比,\ 0\sim1)$$

这就是 PWM（脉宽调制）。下面把占空比从 0 拖到 100%，注意那条虚线 —— 它就是电感「真正感受到」的电压：

后面所有看起来玄乎的东西，全都是这一句话的推论。

4.2 第 1 步：逆变器其实只有 8 种状态

三相逆变器有 3 个桥臂（A、B、C），每个桥臂上下两个开关管，永远一通一断（同时通 = 电源短路炸管）。

所以每个桥臂只有 2 种状态，三个桥臂一共 $2^3 = 8$ 种。我们用 1 表示「上管通、这相接到 $+U_{dc}$」，0 表示「下管通、这相接到 0」。

关键问题：每一种开关组合，电机三相绕组上实际看到的是什么电压？

先记住一件事：电机是三线制，没有中线，所以中性点是「浮动」的。表里说的「相电压」是相对电机中性点的电压，不是相对 GND 的。手算一遍你就懂了 —— 以 100 为例（A 接 $+U_{dc}$，B、C 接 GND）：
  1. 先写三相对 GND 的电压：$v_a'=U_{dc},\quad v_b'=0,\quad v_c'=0$
  2. 中性点电位 = 三相的平均值（因为三相电流之和恒为 0）：$v_n=\dfrac{U_{dc}+0+0}{3}=\dfrac{1}{3}U_{dc}$
  3. 相电压 = 各自对 GND 的电压 减去 中性点电位：
    $v_a=U_{dc}-\dfrac{1}{3}U_{dc}=\dfrac{2}{3}U_{dc}$　$v_b=0-\dfrac{1}{3}U_{dc}=-\dfrac{1}{3}U_{dc}$　$v_c=-\dfrac{1}{3}U_{dc}$
表里那些 $\dfrac{2}{3}$、$\dfrac{1}{3}$ 就是这么来的。一句话记住：几相接正，中性点就被抬到几分之几。
一相接正（如 100）→ 中性点抬到 $\dfrac{1}{3}$；两相接正（如 110）→ 抬到 $\dfrac{2}{3}$，于是 $v_a=v_b=U_{dc}-\dfrac{2}{3}U_{dc}=\dfrac{1}{3}U_{dc}$，而 $v_c=0-\dfrac{2}{3}U_{dc}=-\dfrac{2}{3}U_{dc}$。

Q：为什么合成矢量要用「等幅值 Clarke」来算？换一种变换会怎样？
Clarke 变换就是把三相量投影到正交 αβ 轴的标准工具（第 2 章已定义）。等幅值形式下矢量长度 = 相电压幅值，语义最直观：100 说「α 方向上有 $\frac{2}{3}U_{dc}$」，矢量就真的是 $\left(\frac23, 0\right)$。若改用等功率 Clarke（整体乘 $\sqrt{\frac23}$），每个矢量的方向完全不变，只是长度刻度变成 $\sqrt{\frac23}\cdot\frac23 \approx 0.544$ —— 所以「6 个方向、正六边形、60° 间隔」这些结论与变换系数无关。
Q：为什么 6 个有效矢量的大小都恰好是 $\frac{2}{3}U_{dc}$？
代入 Clarke 只有两类结果：「独大」相是 $\left(\pm\frac23, 0\right)$ 类，大小 $\frac23$；「并列」相是 $\left(\pm\frac13, \pm\frac{\sqrt3}{3}\right)$ 类，大小 $\sqrt{\frac19 + \frac39} = \frac23$。数学上靠的是勾股数 $(1, \sqrt3, 2)$，物理上是三相 120° 对称性：3 个桥臂的 6 种非零组合，任意一种绕原点转 120° 都能变成另一种，所以长度必然相等。
Q：101 是「C、A 并列」，为什么是 300° 而不是 60°？
并列矢量指向两相轴线的正中间。A 轴在 0°，C 轴在 240°（即 −120°），中间是 −60° = 300°。最常见的坑是把 C 轴当成 120° —— 120° 是 B 轴的位置。检验法：代入 Clarke 得 $\left(\frac13, -\frac{\sqrt3}{3}\right)$，$\mathrm{atan2}\!\left(-\frac{\sqrt3}{3}, \frac13\right) = -60° \equiv 300°$，无误。
Q：表里的角度是相对谁的？
相对 α 轴（与 A 相绕组轴线重合），逆时针为正 —— 与第 2 章 Clarke 的坐标定义、图 4-2 的六边形画法完全一致：U₁ 在 0°（正右方），逆时针每 60° 一个。
Q：000 和 111 对电机效果一样，为什么还要保留两个零矢量？
对电机而言两者都让线电压为零、完全等价；但七段式 PWM 需要在一周期内交替使用 U₀ 和 U₇ 各一半，才能让三相波形左右对称、每相一个周期只开关两次（详见 4.4）。所以两个零矢量不是冗余，是工程需要。
Q：中性点电位为什么就是三相的平均值？
电机三线制、无中线，$i_a + i_b + i_c = 0$。中性点必须自动浮动到「三相电压之和为零」的位置，解出来正是 $v_n = (v_a' + v_b' + v_c')/3$。这也是口诀「几相接正，中性点就被抬到几分之几」的出处。

  • 哪两相是 +1/3（并列），矢量就指到这两相轴线的正中间：AB → 60°，BC → 180°，CA → 300°
  • 三相相电压加起来恒等于 0（表里每一行都是），因为中性点就是这么定义的
  • 6 个有效矢量大小完全一样，都是 $\frac{2}{3}U_{dc}$，区别只有方向 —— 所以它们的端点正好落在一个正六边形的 6 个顶点上；两个零矢量大小为 0，都落在原点

4.3 第 2 步：只有 6 个方向怎么办 —— 用「平均」凑

现在目标矢量指向 37°，可我只有 0° 和 60° 两个家伙。怎么办？

打个比方：曼哈顿打车。
曼哈顿的街道只有横平竖直两个方向，可你要去东北方向的斜街。司机会怎么做？
—— 一会儿向东开，一会儿向北开，来回切。你从直升飞机上看，车的平均轨迹就是那条朝东北的斜线。切得越快，轨迹越接近直线。

电机绕组（电感）就是那个「从直升飞机上看」的视角。

写成式子，就是所谓的伏秒平衡（volt-second balance）—— 名字吓人，意思就是「电压 × 时间的总面积相等」：

$$\vec U_{ref}\,T_s = \vec U_k\,T_k + \vec U_{k+1}\,T_{k+1} + \underbrace{\vec 0 \cdot T_0}_{零矢量}$$

两边除以 $T_s$，就是一句大白话：

$$\boxed{\ \vec U_{ref} = \underbrace{\frac{T_k}{T_s}}_{权重} \vec U_k + \underbrace{\frac{T_{k+1}}{T_s}}_{权重} \vec U_{k+1} + \frac{T_0}{T_s}\cdot \vec 0\ }$$

平均矢量 = 几个矢量按时间加权求和。这就是 SVPWM 的全部数学。下面你自己拖两个滑块试试：

  • 方向由 $T_k : T_{k+1}$ 的比例决定。两个矢量的加权平均，端点必然落在它们连成的那条线上 —— 这条线就是扇区的边界。
  • 大小由零矢量「掺多少」决定。零矢量贡献为 0，掺得越多，平均矢量就被往原点拉得越短。想调幅？掺零矢量。
  • 所以两个相邻矢量 + 零矢量，能覆盖它们围成的整个三角形，也就是一个扇区。6 个扇区拼起来 = 整个六边形。
线性调制上限：$T_k + T_{k+1}$ 最大只能是 $T_s$（不能再掺零矢量了），此时平均矢量端点正好落在六边形边上。要保证转一圈的每个角度都不超，矢量端点轨迹必须落在六边形的内切圆里，半径 $\frac{2}{3}U_{dc}\cos 30^\circ = \frac{1}{\sqrt3}U_{dc} \approx 0.577\,U_{dc}$。这就是 SVPWM 能输出的最大相电压幅值。

4.3.1 扇区法：把所有细节算出来

先明确本节定位，别搞反了主次。
工程代码里最常用的是 4.6 节的零序注入法（5 行、无分支、不易错），本节讲的扇区法主要用来理解原理。
那为什么还要学扇区法？三个理由：① 伏秒平衡是 SVPWM 的物理本质，$T_1/T_2/T_0$ 让你知道「为什么能输出这么大电压」，而零序注入法是等价变换，它只告诉你「这么做就对了」，不告诉你为什么；② 做过调制（往六阶梯过渡）必须知道扇区和边界；③ 单电阻电流重构必须知道当前扇区和有效矢量窗口。所以面试要会、进阶要用，但写代码优先用零序注入。

上面讲了「用平均凑」的原理，但还有三件事没落地：① 目标矢量落在哪个扇区怎么判 ② 作用时间具体怎么解 ③ 为什么教材里有好几套公式。这一节把它们一次说清 —— 这就是所谓的扇区法（也叫投影法），是教科书和面试的标准答法。

第一步：扇区怎么分

6 个有效矢量端点构成正六边形，从原点引向顶点，把平面切成 6 个 $60°$ 的三角形，就是 扇区（sector）。

编号约定（本章统一）：扇区 $s$ 覆盖角度 $[60°(s-1),\ 60°s)$，由 $\vec U_s$ 与 $\vec U_{s+1}$ 合成，下标对 6 取模（$s=6$ 时用 $\vec U_6,\vec U_1$）。即扇区 1 = $0°\sim60°$，由 $U_1(0°)$ 和 $U_2(60°)$ 合成 —— 与图 4-3 的扫扇区演示完全对应。

先说清一个容易把人绕晕的点：扇区「编号」不是唯一的。
本章 4.9 节代码里的扇区编号，刻意对齐了几何扇区（$s=1 \leftrightarrow 0°\sim60°$），代价是查表 lut = {0,2,6,1,4,3,5,0} 看起来像乱码。
而很多教材 / TI 文档里的「扇区号」是按符号位 code 的直接映射（code 1→I、2→II …），编号与几何角度差一个旋转。
两者都对，但绝不能混用：扇区号错一位，查表得到的占空比就是错的，表现为某一片角度转矩异常、电机抖动。认准一套，用 4.9 节的自测程序扫 360° 验证。

第二步：作用时间的两种算法

算法 1：投影法（几何解，不用三角函数）

设 $\vec U_{ref}$ 在扇区 $s$ 内，$\vec U_s,\vec U_{s+1}$ 之间夹角 $60°$，$\theta'$ 是 $\vec U_{ref}$ 相对 $\vec U_s$ 的角。分别在 $\vec U_s$ 及其垂线两个方向投影：

$$U_{ref}\cos\theta' = \frac{T_s}{T_{s+1}}\cdot\frac{2}{3}U_{dc},\qquad U_{ref}\sin\theta' = \frac{T_{s+1}}{T_s}\cdot\frac{2}{3}U_{dc}\cdot\frac{\sqrt3}{2}$$

整理即得大家熟悉的两条公式：

$$\boxed{\;T_1=\frac{\sqrt3\,T_s}{U_{dc}}\left(\frac{\sqrt3}{2}u_\alpha-\frac{1}{2}u_\beta\right),\qquad T_2=\frac{\sqrt3\,T_s}{U_{dc}}\,u_\beta\;}$$

算法 2：预计算 $X,Y,Z$（工程写法，最省算力）

把 $\vec U_{ref}$ 分别投影到三条扇区分界线上，再统一乘 $\sqrt3$，得到三个「投影量」：

$$\boxed{\;X=\sqrt3\,u_\beta,\qquad Y=\frac{3}{2}u_\alpha+\frac{\sqrt3}{2}u_\beta,\qquad Z=-\frac{3}{2}u_\alpha+\frac{\sqrt3}{2}u_\beta\;}$$

于是扇区判断和作用时间都退化成查表：扇区由三个符号位拼成 code（0~7，两个零矢量对应的 0 和 7 不会出现）唯一确定；作用时间就是 $X,Y,Z$ 的正负组合。

第四步：内切圆、外接圆，和那 15%

$\vec U_{ref}$ 端点能到的最远距离分三个环：

  • 内切圆 $r=\frac{2}{3}U_{dc}\cos30°=\frac{U_{dc}}{\sqrt3}\approx0.577U_{dc}$ —— 转一圈任何角度都不饱和，这是线性调制区上限（调制度 $m=1$）。
  • 外接圆 $r=\frac{2}{3}U_{dc}\approx0.667U_{dc}$ —— 只有顶点方向够得着，对应六阶梯（方波）调制的基波极限，$m=2/\sqrt3\approx1.1547$。
  • 圆外但六边形内 —— 过调制区：$\vec U_{ref}$ 端点被迫落在六边形边上，波形削顶、谐波骤增，但基波还能再挤出一点电压。

为什么偏偏是 $\dfrac{1}{\sqrt3}$？ 六边形内切圆半径 = $\vec U_k$ 长度 $\times\cos30°$。而 $\vec U_k$ 长度是 $\frac{2}{3}U_{dc}$（4.2 节已证），于是 $\frac23\cdot\frac{\sqrt3}{2}=\frac{U_{dc}}{\sqrt3}$。它是「六边形是内切圆的外切多边形」这一几何事实的推论，不依赖任何调制算法。线性区最大相电压 $\dfrac{U_{dc}}{\sqrt3}$ 对比 SPWM 的 $\dfrac{U_{dc}}{2}$，比值 $\dfrac{2}{\sqrt3}=1.1547$，就是那个著名的 15.5%。

第五步：七段式顺序为什么是唯一的

4.4 节列了三个要求，这里说明它们如何共同把顺序「逼」成唯一解：

  1. 左右对称 → 一个周期内的矢量序列必须是回文；
  2. 零矢量一分为二 → 首尾各 $T_0/2$（$U_0$、$U_7$ 各一半），这是「七段」而非「五段」的原因；
  3. 相邻段只准动一个桥臂 → 在回文骨架里插 $\vec U_s,\vec U_{s+1}$，只有 $U_0\!\to\!U_s\!\to\!U_{s+1}\!\to\!U_7$ 这一条路径满足（任意两个相邻的 $\vec U_k$ 之间都会同时动两个桥臂）。

所以七段式不是「习惯写法」，而是三个约束下的唯一拓扑；工程上的「五段式」（只用一个零矢量、居中对称）则主动放弃第 2 条，代价是共模跳变更大、谐波更差。

4.4 第 3 步：这几段时间怎么排？（七段式）

我们现在知道「U₁ 出 0.35、U₂ 出 0.40、零矢量出 0.25」。但在一个周期里按什么顺序出，还没定。

排法有讲究，要满足三个要求：

  • 每次只动一个桥臂 —— 动一次开关就有一次开关损耗，能省则省
  • 波形左右对称 —— 对称的波形谐波更小
  • 零矢量一分为二 —— U₀(000) 和 U₇(111) 各出一半

唯一满足全部要求的排法，就是经典的七段式：

U₀(000) → U₁(100) → U₂(110) → U₇(111) → U₂(110) → U₁(100) → U₀(000)

看出来了吗 —— 顺序是左右完全对称的，而且相邻两段之间只变一个桥臂（000→100 只动 A，100→110 只动 B，110→111 只动 C）。所以一个周期里每相只开关两次。

4.6 一个更省事、且完全等价的写法

上面「判扇区 → 算时间 → 查表换成占空比」这一套，是教科书和面试的标准答案，但代码又长又容易写错（向量作用时间算错、查表顺序错，是新手最常见的坑）。

工程上更常用的是零序注入法。它绕开了扇区，只有 5 行（下面 $v$ 都已按 $v = u/U_{dc}$ 标幺：占空比 0.5 ↔ 相电压为 0，占空比 1 ↔ 桥臂中点平均电压 = $U_{dc}$）：

  1. 先用反 Clarke 把 $u_\alpha,u_\beta$ 还原成三相正弦 $v_a, v_b, v_c$（这就是你真正想要的三相电压）
  2. 找出三相里的最大值 $v_{max}$ 和最小值 $v_{min}$，取中点 $v_{mid} = (v_{max}+v_{min})/2$
  3. 三相都减去这个中点，再加 0.5，就得到占空比
$$D_x = v_x - \frac{v_{max}+v_{min}}{2} + \frac{1}{2}\qquad (x = a,b,c)$$
常见疑问：式子里的「+½」是不是和零序分量算重了？零输出对应的占空比不就是 0.5 吗？
没有算重，这是两个不同角色的量：
① $-\dfrac{v_{max}+v_{min}}{2}$ 是零序注入量——它不是常数，而是一个随转角摆动的三角状波（以 3 次谐波为主，幅值只有 ±A/4，均值为 0），负责把三相信号的包络搬到正中间，压扁成马鞍形（见 4.7）；
② $+\dfrac{1}{2}$ 是恒定台阶——相电压本来就以母线中点 $U_{dc}/2$ 为参考：占空比 0.5 时桥臂中点的平均电压恰好是 $U_{dc}/2$，输出相电压为零。它只是把以 0 为中心的双极性电压线性映射到 [0,1] 的占空比区间，与调制深浅无关。
所以「归一化以后零输出 = 0.5 占空比」这句是对的：零调制时 $v_x = 0$，三相占空比恒为 0.5 —— 对应 4.5 表里七段式的对称结构：两端的 $T_0/4$（$V_0$）与中间的 $T_0/2$（$V_7$），正好各拿一半零矢量时间。但 0.5 是地基，零序分量是在地基上随角度起伏的信号，二者相加并不重复。

为什么可以这么干？因为电机是三线制，没有中线，三相电压里同时加一个相同的量（零序分量）不会改变任何线电压，电机完全感觉不到。所以我们爱怎么平移就怎么平移。把三相整体挪到「刚好不超出 0~1」的中间位置，就是在最大化利用母线电压 —— 而这件事，恰好等价于掺入最优的零矢量。

结论：在线性调制区内，零序注入法与经典 SVPWM 的输出逐位相同，是同一件事的两种写法。本站已用数值方式验证过：360 个角度 × 20 个调制度下，两者占空比完全一致，且由占空比反算回来的 $u_\alpha,u_\beta$ 误差在 $10^{-16}$ 量级（即浮点精度极限）。

4.7 马鞍波，以及那多出来的 15%

零序注入法顺带解释了一个困扰很多人的现象：为什么 SVPWM 的三相占空比波形是「马鞍形」，不是正弦？

因为被减掉的 $v_{mid}$ 本身不是常数，它是个三倍频的三角波。三次谐波在三相里是同相的（零序），注入它不影响线电压，但会让相电压调制波被「压扁」成马鞍形。

这么折腾图什么？为了多要 15% 的电压。

  • SPWM（傻办法）：直接把三相正弦当调制波，幅值最大只能到 $\pm 0.5\,U_{dc}$（超出就削顶失真），相电压幅值上限 $= U_{dc}/2$
  • SVPWM：靠注入零序把波形压扁，把幅值上限推到 $U_{dc}/\sqrt3 \approx 0.577\,U_{dc}$
  • 两者之比 $\dfrac{1/\sqrt3}{1/2} = \dfrac{2}{\sqrt3} \approx 1.1547$，整整高出 15.5%

同样一块电池，SVPWM 能让电机转得更快、出力更大，或者反过来用更低的母线电压达到同样性能。这就是它一统江湖的原因。

图 4-5：左：空间矢量六边形，$\vec U_{ref}$（白）由相邻两个矢量（绿）合成，虚线圆是线性调制上限。右：三相占空比波形 —— 这就是「马鞍波」。点「对比 SPWM」可以看到被压扁的马鞍波相对纯正弦鼓出了多少；把调制度拖过 100% 能看到超出六边形后波形开始削顶（过调制）。
满调制（调制度 100%，$|U_{ref}| = U_{dc}/\sqrt3$）到底长什么样？
① 打满的是正弦项，零序分量照旧存在：相电压幅值 $A = U_{dc}/\sqrt3$，注入量峰值仍是 $A/4 \approx 0.144\,U_{dc}$（0~3V 端电压视角里是 0.433 V）。因为最坏角度上 $v_{max}-v_{min}$ 恰好等于整个调制范围，此时占空比刚好铺满 [0,1]，每 60° 有一相贴到 0、另一相贴到 1（贴轨的那一相这一周期完全不开关）；
② 三相占空比的共模电平并不是恒定的 0.5：三个正弦加起来恒为 0，所以公共部分恒等于 $\tfrac13(D_a+D_b+D_c) = 0.5 - v_{mid}$，随角度在 0.5 上下摆动 ±0.144（0~3V 视角里就是 $1.5\text{V} + k$，$k$ 峰值 0.433 V）。「1.5 V 减零序分量」说的是这个共模电平，不是占空比本身 —— 占空比 = 正弦项 + 这个共模电平；
③ 满调制 ≠ 零矢量为零：内切圆上零矢量占比 $t_0$ 在 0（六个切点，即扇区分界线）到 0.134（扇区中线）之间变化；再往外（>100%）就是过调制，min-max 公式会算出越界的占空比，必须限幅，波形随之畸变。

4.8 面试视角：PWM 工程细节

SVPWM 算出的占空比要真正变成栅极驱动信号，还有两个工程问题面试爱问：死区和更新时序。

死区（dead time）：同一桥臂上下两管绝不能同时导通（直通短路烧管），所以切换时要插入两管都关断的死区时间（几十 ns 到几 μs）。但死区会让实际输出电压偏离指令：死区期间电流方向决定哪个续流二极管导通，电流为正时实际电压被拉低、为负时被拉高，误差符号只取决于电流极性。低频时误差占比大，表现为相电压波形畸变、低速转矩脉动。补偿思路：按电流极性给占空比加/减一个死区等效修正量（硬件法或软件查表/在线自适应）。

单更新 vs 双更新：中心对齐 PWM 一个周期有峰、谷两个时刻可以更新占空比寄存器。

  • 单更新：每周期只在一处更新，占空比最长滞后一个周期，电流环带宽受限，但时序简单、与采样对齐容易。
  • 双更新：峰、谷都更新，控制周期减半（开关频率不变），环路带宽可更高，适合高性能伺服；代价是 ISR 频率翻倍、计算预算更紧。
  • 占空比更新要避开采样窗口：先更新占空比、再在有效矢量中段触发 ADC，保证采到的是新占空比下的电流。
Q：用一句话说清 SVPWM 在干什么？
在一个 PWM 周期内，用相邻两个基本矢量加零矢量按时间加权平均，凑出你想要的任意电压矢量；因为电感只看平均值，所以「平均对」就等于「对」。
Q：零矢量是干嘛的？
调幅。它贡献的电压是 0，掺得越多平均矢量越短。同时它不花任何开关动作，是「免费」的调压手段。
Q：SVPWM 扇区怎么判？
由 $u_\alpha,u_\beta$ 的符号组合（或三个投影量 $X,Y,Z$ 的符号）确定 1~6 扇区，再用伏秒平衡算相邻两矢量作用时间。实际写码推荐直接用零序注入法，结果与之一致且不易出错。
Q：SVPWM 比 SPWM 好在哪？
直流电压利用率高约 15.5%（相电压幅值 $U_{dc}/\sqrt3$ vs $U_{dc}/2$），且七段式每周期每相只开关两次、总有一相箝位，同开关频率下开关损耗和谐波都更小。
Q：什么是死区效应？如何补偿？
死区时间内输出电压由电流极性决定（续流管导通），导致实际电压与指令偏差，误差符号随电流极性翻转，低频时占比大、引起波形畸变与转矩脉动。补偿：检测电流极性，对占空比加/减死区等效修正量；进阶方案有在线误差观测/自适应补偿。
Q：PWM 单更新和双更新的区别？
中心对齐 PWM 下，单更新每周期只写一次占空比（控制周期 = PWM 周期），双更新在峰、谷都写（控制周期减半）。双更新把环路带宽提升空间给得更大，但中断频率和计算压力翻倍。

4.9 代码举例

版本 A（推荐，工程常用）：零序注入法，5 行搞定

#include <math.h>
#define SQRT3 1.7320508075688772f

/* 输入：uAlpha,uBeta（已标幺到 Udc，且 |Uref| <= 1/sqrt(3) 保证线性区）
   输出：三相占空比 ta,tb,tc，均在 [0,1] */
void svpwm(float uAlpha, float uBeta, float* ta, float* tb, float* tc) {
    /* 1) 反 Clarke：还原出想要的三相相电压（标幺到 Udc） */
    float va =  uAlpha;
    float vb = -0.5f * uAlpha + SQRT3 / 2.0f * uBeta;
    float vc = -0.5f * uAlpha - SQRT3 / 2.0f * uBeta;

    /* 2) 注入零序分量：整体平移到 [0,1] 的中间位置（等价于掺入最优零矢量）*/
    float vmax = fmaxf(va, fmaxf(vb, vc));
    float vmin = fminf(va, fminf(vb, vc));
    float vmid = 0.5f * (vmax + vmin);

    *ta = va - vmid + 0.5f;
    *tb = vb - vmid + 0.5f;
    *tc = vc - vmid + 0.5f;
}

⚠ 标幺基提醒（新手最容易在这里差 2 倍）：上面这套代码用的是 $v = u/U_{dc}$ 基（线性区 $|v| \le 1/\sqrt3 \approx 0.577$），所以占空比写成 $D = v - v_{mid} + 0.5$。而图 4-5 的可视化用的是另一套基：$\pm 1 = \pm U_{dc}/2$（滑条拉到 1.1547 才是 SVPWM 上限），那里写作 $D = (v - v_{mid} + 1)/2$。两基相差 2 倍、结果完全一致，但不能混用：换了基，「0.5」这个台阶和减中点的系数必须一起换。

版本 B（面试要会）：经典扇区判断 + 伏秒平衡

#include <math.h>
#define SQRT3 1.7320508075688772f

/* 输入：uAlpha,uBeta（标幺到 Udc）；输出：三相占空比 ∈ [0,1]
   扇区编号：s=1..6 对应角度 [60(s-1)°, 60s°)，扇区 s 由 Us 与 U(s+1) 合成 */
void svpwm_sector(float uAlpha, float uBeta, float* ta, float* tb, float* tc) {
    /* 1) 三个投影量：Uref 在 90° / 30° / 150° 三条扇区分界线上的投影 × √3 */
    float X = SQRT3 * uBeta;
    float Y =  1.5f * uAlpha + SQRT3 / 2.0f * uBeta;
    float Z = -1.5f * uAlpha + SQRT3 / 2.0f * uBeta;

    /* 2) 扇区判断
       ⚠ 不要用裸的符号位握手 `(uBeta > 0)`：当 θ 恰为 60° 整数倍时，
          某个握手量本应为 0，但 float 运算后残差并不精确为 0
          （实测 60° 处 −5.96e−8、240° 处 +8.94e−8，**符号随机**），
          裸 `> 0` 会让浮点误差决定扇区归属，导致部分分界点编号偏一位。
       ⚠ 加 EPS 也治不了：残差随机在 ±1e−7，EPS 太小盖不住、太大误伤合法点。
       ✔ 正确做法：用 atan2 判角度，或直接用零序注入法绕开扇区（4.6 节）。
          实测 atan2 版在 float 下 18000 点全域扫描 0 错、六个分界点全对。
       （注：该错位不影响占空比输出，但会让「逐扇区不等价处理」的代码出错） */
    const float PI_F = 3.14159265358979f;
    float ang = atan2f(uBeta, uAlpha);         /* (-π, π] */
    if (ang < 0.0f) ang += 2.0f * PI_F;        /* → [0, 2π) */
    int s = (int)(ang / (PI_F / 3.0f)) + 1;    /* 0..5 → 1..6 */
    if (s > 6) s = 6;

    /* 3) 伏秒平衡：解出两个相邻矢量的作用时间（已除以 Ts）*/
    float t1, t2;                      /* t1 = 小角度那个矢量，t2 = 大角度那个 */
    switch (s) {
        case 1: t1 = -Z; t2 =  X; break;
        case 2: t1 =  Y; t2 =  Z; break;
        case 3: t1 =  X; t2 = -Y; break;
        case 4: t1 =  Z; t2 = -X; break;
        case 5: t1 = -Y; t2 = -Z; break;
        default:t1 = -X; t2 =  Y; break;   /* s = 6 */
    }
    /* 过调制限幅：超出六边形时按比例缩回 */
    if (t1 + t2 > 1.0f) { float k = 1.0f / (t1 + t2); t1 *= k; t2 *= k; }
    float t0 = 0.5f * (1.0f - t1 - t2);    /* 半个零矢量时间 */

    /* 4) 时间 -> 占空比：看每相在七段里哪几段导通 */
    switch (s) {
        case 1: *ta = t1+t2+t0; *tb = t2+t0;    *tc = t0;        break;
        case 2: *ta = t1+t0;    *tb = t1+t2+t0; *tc = t0;        break;
        case 3: *ta = t0;       *tb = t1+t2+t0; *tc = t2+t0;     break;
        case 4: *ta = t0;       *tb = t1+t0;    *tc = t1+t2+t0;  break;
        case 5: *ta = t2+t0;    *tb = t0;       *tc = t1+t2+t0;  break;
        default:*ta = t1+t2+t0; *tb = t0;       *tc = t1+t0;     break;  /* s = 6 */
    }
}

自测程序：怎么确认你写的 SVPWM 是对的

这是一个非常好用的验证思路，自己写完后一定要跑一遍：把算出来的占空比反推回电压，看能不能还原输入的 $u_\alpha,u_\beta$。如果还原误差在 $10^{-6}$ 以内，说明扇区判断、时间计算、占空比查表三步全对；如果某一片扇区误差巨大，那一定是那几个 case 写错了。

#include <math.h>
#include <stdio.h>
#define SQRT3 1.7320508075688772f

/* 占空比 -> 相电压 -> Clarke，反推 uAlpha,uBeta。用于自检 */
void duty_to_ab(float da, float db, float dc, float* ua, float* ub) {
    float va = da - 0.5f, vb = db - 0.5f, vc = dc - 0.5f;  /* 对母线中点 */
    float vn = (va + vb + vc) / 3.0f;                      /* 中性点电位 */
    va -= vn; vb -= vn; vc -= vn;                          /* 真正的相电压 */
    *ua = (2.0f/3.0f) * (va - 0.5f*vb - 0.5f*vc);
    *ub = (2.0f/3.0f) * (SQRT3/2.0f*vb - SQRT3/2.0f*vc);
}

int main(void) {
    float worst = 0.0f; int worst_deg = 0;
    for (int deg = 0; deg < 360; deg++) {
        float mag = 0.8f / SQRT3;                    /* m=0.8，落在线性区内 */
        float th  = deg * (float)M_PI / 180.0f;
        float ua0 = mag * cosf(th), ub0 = mag * sinf(th);
        float ta, tb, tc;
        svpwm(ua0, ub0, &ta, &tb, &tc);
        if (ta<0||ta>1||tb<0||tb>1||tc<0||tc>1) { printf("越界 %d\n", deg); return 1; }
        float ua1, ub1;
        duty_to_ab(ta, tb, tc, &ua1, &ub1);
        float err = hypotf(ua1 - ua0, ub1 - ub0);
        if (err > worst) { worst = err; worst_deg = deg; }
    }
    printf("最大还原误差 = %.3e (最差角度 %d°)\n", worst, worst_deg);
    /* 正确实现应该打印 ~1e-7（float）*/
    return 0;
}

5.1 完整控制框图

把前四章串起来，完整的 FOC 电流环 + 速度环结构如下：

图 5-1：FOC 双闭环控制框图。外环为速度环，输出 $i_q$ 指令；内环为电流环（dq 解耦），输出经反 Park → SVPWM 驱动逆变器。位置/速度由编码器或观测器获得。

5.2 信号流（一个控制周期的完整旅程）

  1. 采样：ADC 读取两相电流 $i_a,i_b$（$i_c=-i_a-i_b$），编码器读取机械角度 $\theta_m$
  2. Clarke：$i_a,i_b \to i_\alpha,i_\beta$
  3. 电角度：$\theta_e = p\,\theta_m$（$p$ 为极对数）
  4. Park：$i_\alpha,i_\beta \to i_d,i_q$（需要 $\theta_e$）
  5. 速度环 PI：$\omega_{ref}-\omega \to i_{q,ref}$；通常 $i_{d,ref}=0$
  6. 电流环 PI：$i_{d,ref}-i_d \to u_d$，$i_{q,ref}-i_q \to u_q$
  7. 反 Park：$u_d,u_q \to u_\alpha,u_\beta$（需要 $\theta_e$）
  8. SVPWM：$u_\alpha,u_\beta \to$ 三相占空比 → 定时器 PWM 输出

5.3 PI 控制器与解耦补偿

dq 轴电压方程存在交叉耦合项。PMSM 在 dq 系下的稳态电压方程：

$$ \begin{aligned} u_d &= R_s i_d + L_d\dfrac{di_d}{dt} - \omega_e L_q i_q\\ u_q &= R_s i_q + L_q\dfrac{di_q}{dt} + \omega_e (L_d i_d + \psi_r) \end{aligned} $$

交叉项 $-\omega_e L_q i_q$ 和 $\omega_e(L_d i_d + \psi_r)$ 会让 d、q 轴互相干扰。工程上常加前馈解耦补偿，把交叉项在控制器输出端抵消，使两个电流环真正独立：

$$ u_d = u_d^{PI} - \omega_e L_q i_q,\qquad u_q = u_q^{PI} + \omega_e (L_d i_d + \psi_r) $$

PI 参数整定常用“极点配置法”：把电流环近似为一阶惯性环节，按期望带宽 $\omega_c$ 取 $K_p = \omega_c L$，$K_i = \omega_c R_s$。

带宽分级设计经验（面试常问）：电流环带宽通常取开关频率的 $1/10$ 左右（受采样+计算+PWM 滞后约 1.5 个控制周期的限制）；速度环带宽取电流环的 $1/5 \sim 1/10$，保证内外环时间尺度分离，否则内环没来得及响应外环就振荡了。另外电流环几乎从不加 D：电流信号本身噪声大，微分会放大开关噪声，且一阶对象用 PI 已能无静差跟踪。

5.4 代码举例 1：一个最小可用的 FOC 电流环（C）

typedef struct { float kp, ki, integ, out_max; } pi_t;

float pi_update(pi_t* pi, float err, float dt) {
    pi->integ += pi->ki * err * dt;
    // 抗积分饱和
    if (pi->integ >  pi->out_max) pi->integ =  pi->out_max;
    if (pi->integ < -pi->out_max) pi->integ = -pi->out_max;
    float out = pi->kp * err + pi->integ;
    if (out >  pi->out_max) out =  pi->out_max;
    if (out < -pi->out_max) out = -pi->out_max;
    return out;
}

// 每 50~100us 调用一次
void foc_current_loop(float ia, float ib, float theta_e,
                      float id_ref, float iq_ref, float dt) {
    // 1. Clarke
    float alpha = ia;
    float beta  = (ia + 2.0f * ib) * 0.57735027f;
    // 2. Park
    float c = cosf(theta_e), s = sinf(theta_e);
    float id =  alpha * c + beta * s;
    float iq = -alpha * s + beta * c;
    // 3. 电流环 PI
    float ud = pi_update(&pi_d, id_ref - id, dt);
    float uq = pi_update(&pi_q, iq_ref - iq, dt);
    // 4. 反 Park
    float u_alpha = ud * c - uq * s;
    float u_beta  = ud * s + uq * c;
    // 5. SVPWM → 写定时器比较寄存器
    float ta, tb, tc;
    svpwm(u_alpha / UDC, u_beta / UDC, &ta, &tb, &tc);
    set_pwm_duty(ta, tb, tc);
}

前五章解决“算法怎么算”，本章解决“系统怎么跑”。这些内容不会出现在教科书公式里，却是实际项目和面试中被追问最多的部分。

6.1 完整启动流程：从上电到转起来

一个可靠的 FOC 系统上电后通常按以下顺序走：

  • 上电自检：母线电压是否在范围、温度传感器/编码器通信是否正常、驱动使能是否就绪。
  • 采样偏置校准：电机未转时采集电流若干周期求平均，存为零点偏置（见 2.5）。
  • 角度对齐：有编码器时做机械零点与电角度零点对齐（定位到已知电角度，常用给定 $i_d$ 把转子拖到对齐位置再记录 Z 信号/计数值）；同时确认极对数与旋向一致。展开讲见 6.2。
  • 开环拖拽（无感场景）：以给定频率/幅值强制旋转电压矢量把电机慢慢拖起来，待反电动势足够大、观测器收敛后无扰动切换到闭环。
  • 闭环接管：切换瞬间要保证电压/电流指令连续（无缝切换），否则会有明显的顿挫或过流。
常见坑：偏置没校好 → 低速转矩脉动；角度对齐差一个电周期（多极对数电机易错）→ 启动就反转/过流；开环切闭环时机太早 → 观测器未收敛导致失步啸叫。

6.2 角度对齐与编码器校准：以 MT6701 为例

6.1 说的「角度对齐」到底在对什么？一句话：Park 变换和电流环只认电角度，而电角度是从编码器读数换算出来的——对齐就是把换算链路里的未知常数测出来：

$$\theta_e = \mathrm{dir}\times\big(\theta_{enc}-\theta_{offset}\big)\times p \pmod{360^\circ}$$

三个「零点」不是一个东西，它们差着一个固定偏角，校准的任务就是把这个差量出来：

名词由谁决定性质
机械零点（d 轴零位）电机物理结构：转子 N 极指向 A 相绕组轴线时，约定电角度 = 0物理存在，但把哪个位置「叫零」是约定
编码器零点编码器出厂与安装：芯片感受到的 0° 读数位置与转子 d 轴毫无天然关系，装哪算哪
offset上面两者之差，一个常数校准 = 把它测出来存起来

offset 不准的症状分两档：偏一点 → d 轴没对准，一部分电流变成无用磁化电流，出力下降、转矩纹波、发热；符号反了 → d/q 轴接反变成正反馈，一闭环就飞车或锁死嗡鸣。极对数 p 配错的症状不同：能转，但每机械圈失步一次。

为什么电角度要 ×p？因为电角度量的不是「转子转了多少」，而是「磁场周期走了多少」。转子有 p 对磁极，机械转 1 圈，磁场波形对绕组完整重复 p 个周期：$\psi_a(\theta_m)=\hat\psi\cos(p\,\theta_m)$ —— 反电动势、电感、转矩全部认 $p\,\theta_m$，不认 $\theta_m$ 本身。忘乘 p 的后果：电流矢量转速只有磁场的 1/p，永远产生不了有效定向转矩，只会抖动发热。顺带一条常用结论：电频率 = p × 机械转速（7 对极电机机械 3000 rpm → 电流 350 Hz）。一句话总结：offset 修「安装误差」，×p 修「机械圈 ≠ 磁场圈」，两个独立换算。

MT6701：单圈绝对式磁编码器芯片（麦歌恩 MagnTek，差分霍尔原理）。轴上装一片径向双极磁铁，芯片平放在下方感应磁场方向即可工作：

项目规格（规格书 Rev1.8）
原理 / 量程差分霍尔，0~360° 单圈绝对 —— 上电即知圈内角度，无需找 Z 脉冲
数字接口SSI / I²C 读 14 位绝对角度（16384 步/圈，FOC 首选 SSI）
模拟类输出PWM 或比例模拟电压（12 位）；ABZ 增量 1~1024 线可编程；UVW 1~16 对极可编程
动态性能系统延时 <5 μs，最高 55,000 rpm
其他3.3~5 V 供电；内置 EEPROM（烧写时需 VDD>4.5 V）可存配置；SOP-8 / QFN-16

三个使用要点：①「绝对」是单圈绝对——断电重启仍知道圈内角，但不知道转了几圈；②做 FOC 用 SSI 读 14 位角度，别用 ABZ/PWM（分辨率与延迟都差）；③磁铁与芯片的同轴度是精度大头，且机械误差会被 ×p 放大——偏心 1° 机械角，7 对极下就是 7° 电角度误差。

校准流程：开环「强吸」→ 记 offset → 定方向 → 闭环。对齐那一刻必然是开环的（你恰恰是要测量编码器与转子的关系，此刻没有可用反馈），而且它不「转」，是「吸」：

  1. 对齐（测 offset）：电压矢量固定在 $\theta_e=0$（d 轴指向 A 相轴线），$i_q=0$、$i_d$ 给额定电流的 20%~50%，保持约 1 s；转子被磁场吸到唯一平衡位置后，读编码器：$\theta_{offset} = \theta_{enc}$
  2. 方向（测 dir = ±1）：让电角度缓慢匀速正转一圈，编码器读数递增 → +1，递减 → −1（这一步才用「转」，对齐本身不转）
  3. 运行：按开头公式换算，送 Park 变换，切入闭环（电流环 → 速度环 → 位置环）
图 6-1：开环强吸对齐示意。左：电压矢量固定在电角度 0（A 相轴线方向），id 通电把转子 d 轴（N 极）吸到轴线上，此刻转子位置是「已知」的；右：同一时刻读 MT6701，读数 350° 就是 offset。之后编码器每来一个新读数，按 θe = dir × (θenc − 350°) × p 换算成电角度。
/* ① 对齐：矢量固定在电角度 0，把转子“吸”到已知位置 */
set_phase_voltage(U_ALIGN, 0.0f, 0.0f);   /* Uq=U_ALIGN, Ud=0, θe=0 */
delay_ms(1000);                            /* 等转子吸稳 */
float offset = mt6701_read_angle();        /* 记下编码器原始读数 */

/* ② 方向：让电角度缓慢正转一圈，观察编码器是增是减 */
int dir = +1;
float a0 = mt6701_read_angle();
for (float th = 0.0f; th < 2.0f * PI; th += 0.01f) {
    set_phase_voltage(U_ALIGN, 0.0f, th);  /* θe 递增 */
    delay_ms(2);
}
if (mt6701_read_angle() < a0) dir = -1;    /* 读数变小说明装反了 */

/* ③ 运行时：编码器读数 → 电角度（wrap = 取模回绕） */
float theta_e = wrap_2pi(dir * wrap_360(theta_enc - offset) * POLE_PAIRS);
数值例子（p = 7）：对齐吸稳时 MT6701 读 350° → offset = 350°；方向测出 dir = +1。某时刻芯片读 10° → 机械角 = (10 − 350) mod 360 = 20° → 电角度 = 20° × 7 = 140°。减法必须按 360° 取模回绕，且先减 offset 再乘 p（offset 是机械量）——顺序反了结果就错了。

用 SimpleFOC 的话这些全自动：motor.initFOC() 内部就是「强吸 + 慢转一圈定方向」；标定一次后也可以写死参数 motor.initFOC(offset, dir)，上电免对齐、免「咯噔」一下。

常见坑：① 对齐电流太小 / 齿槽转矩大 / 带减速器负载 → 转子没被吸到位，停在隔壁槽 → offset 差一个槽距，表现为运行无力。对策：把矢量分别放在多个角度重复对齐，检查 offset 一致性。② 多极电机 + 磁编：偏心误差被 ×p 放大，高要求场合让转子匀速整圈、用指令角 vs 编码器角做最小二乘拟合 offset（顺带拿到每圈周期误差表做补偿）。③ MT6701 的 offset 想掉电保存：烧芯片 EEPROM（注意 VDD>4.5 V）或存 MCU 的 Flash。④ 增量编码器（ABZ）上电不知道绝对位置，要么找 Z，要么每次上电重新对齐——单圈绝对式的 MT6701 没这个烦恼。
Q：编码器零偏一点点会怎样？
d 轴没对准，iq 之外多出无用的磁化电流分量：出力下降、效率变低、有 6 倍频转矩纹波和发热；偏得太多或符号反了就是正反馈，闭环瞬间飞车。
Q：为什么 MT6701 不用找 Z 脉冲？
它是单圈绝对式：SSI 上电直接读出 14 位绝对角。ABZ 增量式才需要上电找 Z 或重新对齐来确定绝对位置。
Q：对齐时为什么是开环？之后呢？
对齐的目的就是测量「编码器说的位置」和「转子真实位置」的关系，此刻不存在可用反馈，只能开环强吸。offset 生效后立即切入闭环运行。

6.3 无感 FOC：没有编码器怎么知道角度

无感方案的核心思想：从电信号里反推转子位置。按转速段分两类：

  • 反电动势法（中高速）：转速起来后反电动势可观，用滑模观测器（SMO）把电流误差作为滑模面，切换项近似反电动势符号，低通滤波后取 $\hat{\theta}_e = -\mathrm{atan2}(\hat{e}_\alpha, \hat{e}_\beta)$；缺点是滑模抖振需要滤波，而滤波引入相位滞后，需按转速做相位补偿。另一类是磁链观测器（电压模型积分反电动势），低速时积分器漂移问题需处理。
  • 高频注入法 HFI（零低速）：反电动势在零速时为零，反电动势法失效。HFI 向定子注入高频电压，利用 IPM 的凸极性（$L_d \neq L_q$）使高频电流幅值随转子位置变化，解调出位置。不依赖转速，但需要凸极电机、有高频噪声。
  • 典型组合：零低速用 HFI 或开环拖拽 → 中高速切到 SMO/磁链观测器，切换区间做平滑过渡。
Q：SMO 的抖振是什么？怎么处理？
滑模控制项是符号函数，会在滑模面附近高频切换，表现为估算角度/电流的高频抖动。工程上用饱和函数/连续化近似符号函数，加低通滤波，再对滤波引入的相位滞后做转速相关补偿。
Q：为什么零速不能用反电动势法？
反电动势 $e = \omega_e\psi_r$ 与转速成正比，零速时为零，信噪比无法支撑观测；只能改用高频注入利用电感凸极性，或开环拖拽先转起来。

6.4 保护与故障处理

面试常问“你们系统做了哪些保护”，按响应速度从快到慢：

  • 硬件过流保护（最快）：采样电阻电压进模拟比较器，超限直接关 PWM 输出（硬件封锁），不经过中断和软件，响应在 μs 级 —— 这是保护功率级的最后一道防线。
  • 过压/欠压：母线过压（制动能量回灌）可开制动泄放或限流；欠压则限制转矩防止过流。
  • 缺相检测：三相电流和异常偏离 $i_a+i_b+i_c\approx 0$ 即可判断，软件低成本实现。
  • 堵转/失步检测：给定速度与实际速度（或观测器估算）长时间偏差过大、或电流持续超限，判定堵转后进入保护/重启流程。
  • 过温降额：MOS 管/电机温度分级处理：先降电流限幅（降额），超硬限才停机，避免突变停机带来的二次冲击。

6.5 嵌入式实现要点

  • 中断优先级：电流环 ISR 最高优先级（50~100μs 周期内必须跑完：采样+Clarke+Park+2×PI+反Park+SVPWM，现代 MCU 通常只占百分之几到十）；速度环可降频在电流环内分频执行；通信/显示等低优先级任务绝不能阻塞控制环。
  • 硬件联动：PWM 定时器比较事件触发 ADC，ADC 转换结束触发中断 —— 采样时刻、计算时刻、占空比更新时刻全部硬件同步，消除软件抖动。
  • 浮点 vs 定点：带 FPU 的 Cortex-M4/M7 直接用 float 即可（本站代码风格）；老式定点 DSP 需 Q 格式，注意三角函数查表、乘累加位宽与饱和处理。
  • 角度表示：常用 0~65535 对应 0~360° 的整数角度，三角函数查表，增量编码器计数直接对齐这种表示，加法溢出自动回绕正好对应角度周期性。

6.6 面试速查：高频问题一句话答案

Q：FOC 的核心思想一句话？
把三相交流变换到跟随转子旋转的 dq 坐标系，让交流量变直流量，用两个 PI 分别独立控制励磁（$i_d$）和转矩（$i_q$）。
Q：等幅值变换和等功率变换的区别？
系数不同：等幅值保证 $|\vec i_{\alpha\beta}|$ 与相电流幅值一致（电机控制主流），等功率保证变换前后功率不变（电网分析常用），两者只差一个 $\sqrt{2/3}$ 系数。
Q：为什么只采两相电流就够了？
三相三线无中线时 $i_a+i_b+i_c=0$，第三相可由另两相算出。
Q：Park 变换后 $i_d,i_q$ 为什么能用 PI 无静差控制？
因为它们已经是随转子同步的直流量，PI 对直流给定天然无静差。
Q：dq 电压方程里的交叉耦合项怎么处理？
$-\omega_e L_q i_q$ 与 $\omega_e(L_d i_d+\psi_r)$ 用前馈解耦在控制器输出端抵消，使 d/q 轴真正独立。
Q：PI 积分饱和（windup）怎么防？
积分项限幅（clamp）+ 输出限幅，进阶用条件积分/反计算（back-calculation）。
Q：SVPWM 扇区怎么判？
由 $u_\alpha,u_\beta$ 的符号组合（即三个投影量 $X,Y,Z$ 的符号）确定 1~6 扇区，再用伏秒平衡算相邻两矢量作用时间。详见 4.5 节，配套自测程序在 4.9 节。
Q：零矢量（000/111）的作用？
补足开关周期剩余时间；七段式对称分配使谐波最小、开关次数最少。
Q：SVPWM 比 SPWM 好在哪？
直流电压利用率高约 15%（相电压幅值可达 $U_{dc}/\sqrt3$），同开关频率下谐波更小。
Q：电流环 PI 怎么整定？
把对象近似为一阶惯性，按带宽 $\omega_c$ 取 $K_p=\omega_c L$、$K_i=\omega_c R_s$；带宽取开关频率的 1/10 左右。
Q：死区效应怎么补？
按电流极性对占空比加/减死区等效修正量，见 4.5。
Q：弱磁怎么做？
高速时注入负 $i_d$ 压低反电动势，使电压矢量保持在椭圆约束内，见 3.5。
Q：无感低速为什么难？
反电动势与转速成正比，低速信噪比太低；需 HFI 或开环拖拽过渡，见 6.3。
Q：硬件过流保护为什么要用比较器而不是中断？
中断响应有 μs 级延迟和软件风险，模拟比较器直接封 PWM 是硬实时、不可被软件阻塞的最后一道防线。

前六章解决“算法怎么算、系统怎么跑”，本章解决“电到底是怎么流的”。控制算法算出的电压矢量，最终要靠驱动板上的功率电路一安培一安培地送到电机绕组里。本章用四张动画图，把驱动板上最容易看懵的四块拓扑拆开讲，图中的流动亮点就是电流本身，切换开关状态观察回路如何变化。先看整板的能量/信号链路：

整板链路一图流：直流电源 $V_{bus}$ → 预充电/母线电容 → 三相逆变桥（6 个 MOSFET）→ 电机；每相电流经采样电阻+运放 → ADC → MCU；母线电压经 Buck 辅助电源 → 12V（驱动 IC）/ 5V / 3.3V（MCU）；MCU 的 PWM 经栅极驱动（自举电路）放大后开关 MOSFET。抓住这条链，任何驱动板都能读懂七八成。

7.1 三相逆变桥主回路：电流的六条门与回家的路

逆变桥是驱动板的心脏：上下各三个 MOSFET 组成三个桥臂，每臂中点接一相电机绕组，母线电容横跨正负母线做能量缓冲。读懂它的关键只有一条：电机绕组是电感，电流不能突变，所以任何时刻每相电流都必须有一条完整的回家回路 —— 要么走导通的 MOSFET，要么走 MOSFET 体内（或外并）的续流二极管。点击按钮切换三种典型状态，观察电流路径：

A 相上管导通：相电流是交流 —— 正半周从 A 相流出，负半周反向流回，都走 Q4/Q8 沟道（方向自动交替）
图 7-1：三相逆变桥（照驱动板实际电路：Q4~Q9 为 CSD18540Q5B，栅极串 12R，下桥臂串 1mΩ 采样电阻）。回路上的箭头与流动点表示电流方向。三种状态分别对应：MOSFET 正向导通、MOSFET 反向导通（同步整流）、体二极管续流。同一桥臂的上下管绝不能同时导通（否则 VBUS 直接短路，俗称炸管），这就是 4.5 节死区时间的由来。
  • 上管导通：电流从母线正极 → 上管漏极→源极 → 相线 → 电机绕组 → 从另一相流回 → 另一相下管 → 母线负极。电流正向流过 MOSFET。
  • 下管导通：电感维持电流方向不变，此时 A 相电流为负，从 V− 经下管“倒着”流进电机 —— MOSFET 反向导通（沟道 + 体二极管），这叫同步整流，也是为什么死区补偿要看电流极性（见 4.5）。
  • 双管关断（死区/续流）：电感电流无处可去，只能通过体二极管续流：负电流相走下管体二极管入电机，正电流相走上管体二极管回母线。二极管导通压降 0.5~1V，所以死区期间输出电压会偏离指令 —— 死区效应的物理根源。
  • 换相瞬间：相电流在上下管之间换流时，先经过死区（二极管续流），再由 PWM 决定走哪个管子。母线电容负责吸收开关瞬间的高频电流尖峰，所以它必须尽量靠近桥臂（减小寄生电感）。
Q：续流回路为什么必须存在？没有它会怎样？
电机绕组电感电流不能突变，关断开关管瞬间若没有续流通路，电感会产生极高电压（$u=L\,di/dt$）击穿 MOSFET。体二极管（或外并肖特基）就是这条泄放通路。
Q：母线电容的作用？为什么要求低 ESL/ESR 且靠近桥臂？
开关频率下电机电流脉动很大，电容就近提供高频环流、稳住母线电压；走线寄生电感会在换相瞬间与电容谐振产生电压尖峰，所以要尽量缩短功率环路。

7.2 自举驱动电路：上管的栅极电源从哪来

MOSFET 导通靠栅源电压 $u_{GS}$。下管源极接地，栅极给个 12V 就完事；但上管源极接在桥臂中点，导通时会被抬到接近 $V_{bus}$，栅极电源必须“悬浮”且跟着中点一起浮动 —— 这就是自举电路要解决的问题：

VS≈GND，12V 经自举二极管给 Cb 充到 ≈12V
图 7-2：自举电路两个状态（FD6288T 驱动 IC，D6 B16WS，C50 1μF）。左状态：下管导通把 VS 拉到地，12V 经 D6 给 C50 充电；右状态：上管导通后 VS 被抬到 $V_{bus}$，VB 点被举升到 $V_{bus}+12V$，C50 就地给驱动级供电，始终保持 $u_{GS}\approx12V$。
  • 充电窗口：只有下管导通（或电流经下管续流）使 VS≈GND 时，12V 才能经二极管给 Cb 充电。所以自举供电不支持 100% 上管占空比 —— Cb 只放不充会掉压，通常要求最低占空比/最短低侧导通时间。
  • 电容选型：每个开关周期 Cb 要给上管栅极电荷 $Q_g$ 充一次，还要供给驱动 IC 静态电流，工程估算 $C_b \ge \dfrac{Q_g \cdot f_{sw} + I_{qbs}}{\Delta V_{max}}$（$\Delta V$ 取允许压降，如 0.5V）。太小上管欠压发热，太大充电慢、二极管应力大。
  • 自举二极管：要快恢复、耐压超过 $V_{bus}$，防止 VS 举升时电荷倒灌回 12V。
Q：为什么上管驱动要用自举？直接用个 12V 电源不行吗？
上管源极电位随开关在 0~$V_{bus}$ 之间跳变，固定电源无法保证稳定的 $u_{GS}$；自举电容跨接在 VB-VS 之间，天然跟随源极浮动。隔离电源方案可以但成本高，自举是性价比之王。
Q：自举电路的局限是什么？
需要定期让下管导通给 Cb 补电，不支持长时间 100% 占空比；超高速/满调制场景需改用隔离电源或电荷泵驱动。

7.3 电流采样电路：毫伏级信号如何变成 ADC 读数

FOC 的血液是电流反馈。采样链路固定三段式：采样电阻把电流变成电压 → 运放放大并抬偏置 → ADC 量化。电阻位置有几种流派，各有取舍：

三电阻：每相独立采样，任意时刻都能读，成本最高
图 7-3：三种采样位置对比。橙色电阻为当前采样点（Rs 1mΩ，IA+/IA− 差分引出），箭头为电流方向；右侧为采样信号链：电阻上的毫伏级压降经运放放大并叠加 $V_{ref}/2$ 偏置后进入 ADC —— 因为电流有正有负，而 ADC 只认 0~$V_{ref}$。
  • 三相电阻（相电流采样）：每相输出线各串一个电阻，任意时刻两相电流都可读，信息最全、控制最灵活，成本最高；电阻在中点附近时共模电压高，需要差分放大。
  • 下桥臂两电阻：电阻放在两个下管源极与负母线之间，只采两相（第三相用 $i_a+i_b+i_c=0$ 算出）。采样时机有讲究：下管导通时才读得到电流，且要避免开关边沿；占空比极高时可能采不到（最小脉宽问题），需要移相采样，见 2.5。
  • 母线单电阻：只在负母线串一个电阻，一个开关周期内电流会呈现不同相的“拼块”，需在多个时刻分别采样再拼出三相电流。成本最低、损耗最小，但对采样时序和重构算法要求最高。
  • 放大与偏置：$$V_{ADC} = G \cdot i \cdot R_s + \frac{V_{ref}}{2}$$ 满量程约束为 $G R_s I_{max} \le \frac{V_{ref}}{2} \cdot 0.9$（留裕量）。偏置 $V_{ref}/2$ 通常由基准分压产生，上电校准零点（见 2.5、6.1）。
  • 硬件过流：采样电压同时进模拟比较器，超限直接封 PWM —— 这是 6.4 所说最后一道防线的物理位置。
Q：两电阻采样为什么要注意采样时刻？
电流只在下管导通时流过下桥臂电阻；某相占空比过高时下管导通窗口太短，ADC 来不及采样，需要调整 PWM 相位（移相）或改采另一相。
Q：为什么要加 $V_{ref}/2$ 偏置？
相电流双向流动，电阻压降有正有负，而单电源 ADC 输入范围是 0~$V_{ref}$，必须把信号抬到中间量程；软件减去偏置（校准值）即得真实电流。

7.4 辅助电源：母线高压如何变成芯片的口粮

电机吃的是几十伏的母线电，MCU 和驱动 IC 却只要 3.3V/12V —— 靠 Buck 降压完成转换。它是所有开关电源的入门拓扑，只有两个回路，动画里交替出现：

开关导通：母线经 L 给输出供电并储能
图 7-4：Buck 降压（照驱动板实际电路：U2 TPS54560，L1 6.8μH，D5 SS34 续流，R15/R17 反馈分压）。内部开关导通时电流走“VBUS→SW→L1→负载”，电感储能；关断时电感电流经 D5 续流。稳态下伏秒平衡给出 $V_{out} = D \cdot V_{in}$，24V→12V 即 D=50%。右侧为板上电源链。
  • 伏秒平衡：稳态时电感平均电压为零，直接导出 $$V_{out} = D \cdot V_{in}$$ 母线 24V 降到 12V，占空比约 50%。电流环 PWM 与电源 PWM 是同一个原理，只是对象不同。
  • 典型电源链：$V_{bus}$ → Buck → 12V（栅极驱动 IC）→ LDO/Buck → 5V（编码器/接口）→ LDO → 3.3V（MCU）。大电流用 Buck（效率高），小电流/低噪声用 LDO。
  • 隔离电源：电机功率地与 MCU 数字地常用单点连接或磁隔离（如 CAN 收发、编码器接口），大功率/高压系统驱动电源也常用隔离 DC-DC，防止功率环路噪声窜入控制电路。
  • 上电时序：母线电压通常先经预充电电阻限流给电容充电，避免上电瞬间大电流冲击；充到一定比例后再闭合主接触器/继电器。
Q：Buck 占空比和输出电压什么关系？依据是什么？
$V_{out}=D\cdot V_{in}$（连续导通模式），依据是电感伏秒平衡：稳态下电感一周期平均电压必须为零，否则电流会持续漂移。
Q：为什么上电要预充电？
母线电容初始电压为零，直接上电相当于短路，浪涌电流会烧保险/触点并拉跨电源；串电阻限流预充，电压上来后再旁路电阻。

7.5 本章小结：新人读板路线图

  • ✅ 逆变桥：电感电流必有回路 —— MOSFET 导通或体二极管续流，同臂上下管互斥（死区）
  • ✅ 自举驱动：下管导通时给 Cb 充电，上管导通时 Cb 悬浮供电，不支持 100% 占空比
  • ✅ 电流采样：电阻→放大→$V_{ref}/2$ 偏置→ADC；三电阻/两电阻/单电阻是成本与性能的权衡
  • ✅ 辅助电源：Buck 两回路，$V_{out}=D\cdot V_{in}$；电源链逐层降压，注意隔离与上电时序
拿到一块陌生驱动板的读法：① 先找最大的电解电容 → 它就是母线电容；② 顺着它两端的粗铜皮找到 6 个 MOSFET → 逆变桥；③ 看桥臂中点连到哪 → 电机相线；④ 找串在铜皮上的毫欧级电阻 → 采样电阻，顺藤摸到运放和 MCU 的 ADC 引脚；⑤ 最后看小电源芯片和电感 → 辅助电源链。功率流永远从 V+ 出发、回到 V−，信号流永远从采样点流向 MCU。

第 8 章 · STM32G4 外设实战：定时器、ADC 与三环调度

前七章讲的是「算法怎么算」。本章讲 MCU 怎么让这套算法每 50 µs 准点跑一次，并且在最干净的那一刻采到电流。这一章是第 5 章控制框图在 STM32G4 上的落地：谁触发谁、谁打断谁、采样点卡在哪里。理解了本章，再看任何一份 FOC 工程的 tim.c / adc.c 都不会陌生。

本章的主角只有三件事：① TIM1 产生 20 kHz 中心对齐 PWM，并在三相下管同时导通的时刻"打一枪"；② ADC1+ADC2 双注入组被这一枪同时触发，在一个中断里拿到 3 路相电流和母线电压；③ 电流环跑在这个 ADC 中断里，速度环/位置环靠软件分频挂在后面。整章所有配置都围绕这三点服务。

8.1 先定节拍：为什么电流环跑在 ADC 中断，而不是定时器中断

直觉上「PWM 周期到了就跑一次电流环」，于是很多人把 FOC 塞进 HAL_TIM_PeriodElapsedCallback()。这在简单项目里能跑，但有硬伤：更新事件（UEV）的时刻与"电流已经稳定、可以采样"的时刻不是一回事。ADC 转换需要时间，触发点和中断点之间隔着固定的转换延迟；而 UEV 出现在计数器的边界，跟你的调制占空比无关，无法保证此刻采样窗口是干净的。

正确做法是让 ADC 的转换完成中断（JEOC）成为电流环的心跳：TIM1 只负责在精确时刻触发采样，ADC 转完后回调里直接跑 Clarke → Park → PI → iPark → SVPWM，算完写 CCR，影子寄存器在下一个周期边界统一生效。这样「采样 → 计算 → 更新占空比」是一条闭环因果链，延迟恒定且可预测。

工程里的原话（v2.0 与 v3.0 的 fun.c 注释完全一致）：

// TIM1 ch1-3 和 ch1N-ch3N 发波, PWM_freq = 20KHz, PWM模式1
// TIM1 ch4  PWM模式2 不输出, PWM_freq = 20KHz
// TIM1 ch4 的通道事件 触发 ADC1 ADC2 同步注入, ADC1 为主 ADC
// ADC 注入完成中断 freq 20KHz, 50us 一次中断

一句话总结：CH4 不接电机、不输出任何波形，它存在的唯一意义就是当"扳机"。这是本章最核心的一个设计，下面 8.2 拆开讲。

8.2 高级定时器 TIM1：中心对齐、死区、RCR 与 CH4 扳机

TIM1 是 STM32 的高级控制定时器，相比 TIM2/TIM3 这类通用定时器，它多了四样 FOC 必需的东西：互补输出（CHxN）、可编程死区（DTG）、刹车输入（BKIN）、重复计数器（RCR）。前三样是给半桥功率级准备的，第四样用来调整更新事件频率。拖动下面的时间轴，观察一个完整的 PWM 周期：

图 8-1：TIM1 中心对齐模式 1 的完整时序，从上到下六层。① 计数器三角波：CNT 从 0 上数到 ARR 再下数回 0，一个 PWM 周期 = 2×(ARR+1) = 8500 个计数 = 50 µs；② CH1（上管栅极）与 ③ CH1N（下管栅极）互补输出，中间的灰色竖带是死区（上下管都关）；④ 桥臂状态带：绿=上管导通、黄=死区、蓝=下管导通，右边标出了此刻电流走哪条路；⑤ CH4 的 OC4REF——它没有物理引脚，只在三角波顶点（CNT=ARR）附近产生一个宽 6 个计数的窄脉冲；⑥ ADC 注入全过程：OC4REF 上升沿 → 采样保持 59 ns → 12 bit 逐次逼近 ≈353 ns → JEOC 中断 → 电流环开跑。注意顶点处三相上管全部关断、下管全部导通，采样电阻里流过的正是相电流。

8.2.1 为什么必须用中心对齐模式

边沿对齐（向上计数）也能发 PWM，但 FOC 一般用中心对齐，原因是谐波与采样窗口：

  • 电流纹波更小：中心对齐把零矢量平摊在半个周期的两端，相电流纹波的基波频率等于开关频率，且幅值比边沿对齐小，THD 更好。
  • 采样窗口天然居中：三角波的顶点（CNT = ARR）处，三相占空比同时处于"无效电平"——也就是三个下管同时导通的时刻。此时下桥臂分流电阻上的电流就等于该相相电流，是全周期最干净、最长的一段采样窗口。
  • 对称性好：互补通道的开关时刻关于周期中心对称，EMI 频谱更干净。

代价是同样的 PWM 频率，计数周期要减半：中心对齐下一个 PWM 周期包含上数 ARR 个 + 下数 ARR 个共 $2\times ARR$ 个计数，所以

$$f_{PWM}=\frac{f_{CK\_CNT}}{2\,(ARR+1)}\quad\Rightarrow\quad ARR=\frac{f_{CK\_CNT}}{2f_{PWM}}-1$$

本项目：$f_{CK\_CNT}=170\ \text{MHz}$（TIM1 挂在 APB2，PCLK2 = 170 MHz，PPRE2 不分频时 $f_{CK\_CNT}=PCLK2$），目标 20 kHz：

$$ARR=\frac{170\times10^{6}}{2\times 20\times10^{3}}-1=4250-1=4249$$

配合 Prescaler = 0、Counter Mode = Center Aligned Mode 1、Period = 4249。这三个数必须一起对，改频率时只动 ARR。

8.2.2 PSC / ARR / CCR / CNT 到底是什么，它们怎么变

这四个寄存器是 TIM1 的全部"运动部件"。很多教程一上来就让你填数，却不解释它们在物理上是什么动作。一句话概括：PSC 和 ARR 决定"钟摆摆多快、摆多远"，CNT 是"钟摆此刻的位置"，CCR 是"画在墙上的一条刻线"——CNT 扫过刻线的那一刻，输出翻转。

寄存器全称它在干什么谁在改它本项目
PSCPrescaler 预分频器 把定时器输入时钟 $f_{CK\_PSC}$ 分频成计数器实际用的时钟 $f_{CK\_CNT}=f_{CK\_PSC}/(PSC+1)$。它只改变计数快慢，不改变波形形状 初始化时写一次，之后基本不动 0（不分频，170 MHz 直给）
ARRAuto-Reload Register 自动重装载 计数的天花板：CNT 数到 ARR 就掉头（中心对齐）或归零（边沿对齐）。它决定PWM 周期 / 频率 初始化时写一次；改开关频率时才改 4249 → 20 kHz
CCRCapture/Compare Register 捕获比较 与 CNT 实时比较的阈值。CNT 与 CCR 的大小关系决定输出电平，也就决定占空比 每个 FOC 周期都改——SVPWM 算完就写 CCR1/2/3 每 50 µs 更新一次
CNTCounter 计数器 当前计数值，硬件自己 0→ARR→0 循环跑，你不需要也不应该手动写它 硬件自动（启动/相位对齐时可写一次） 0 ↔ 4249 循环

它们之间的关系只有两条式子：

$$f_{CK\_CNT}=\frac{f_{CK\_PSC}}{PSC+1},\qquad f_{PWM}=\frac{f_{CK\_CNT}}{2\,(ARR+1)}\quad(\text{中心对齐})$$ $$占空比=\frac{CCR}{ARR+1}\ \ (\text{PWM 模式 1，高有效})$$

拖动下面的滑块，看四个量怎么联动 —— 特别注意 PSC 和 ARR 都能改频率，但效果完全不同：PSC 是"粗调"，改一格频率跳一大截（因为它只整除）；ARR 是"细调"，一格一格地挪，而且 ARR 同时决定了占空比的分辨率（ARR 越大，占空比能分得越细）。所以工程上一律 PSC=0、全靠 ARR 定频率，把分辨率拉满。

图 8-2：PSC / ARR / CCR / CNT 的联动关系。上面四张卡片是当前值；中间是计算链——170 MHz 先后被 PSC 和 ARR 两次分频，再加上中心对齐的"÷2"，得到 20 kHz；下面是三角波（CNT）与刻线（CCR）的比较过程：CNT 低于 CCR 时输出高，高于时输出低，于是一条水平刻线和高低电平的边界一一对应。PWM 模式 1 是"CNT < CCR 时输出有效电平"，模式 2 正好相反——这就是 8.2.5 里 CH4 用模式 2 能在顶点得到窄脉冲的原因。
CCR 是怎么"变"的？两个层面要分清：
  • 谁在改：FOC 每算完一拍 SVPWM，就把三个占空比写成 TIM1->CCR1/2/3 = (uint32_t)(duty × ARR)。所以 CCR 每 50 µs 变一次，跟着 Uq/Ud 和电角度 θ 走。CH4 的 CCR4 是例外，它只在初始化时写一次 ARR−3，之后永不改动 —— 因为扳机必须钉死在顶点。
  • 什么时候生效：CCR 和 ARR 都有影子寄存器（preload）。你写的是"预装载值"，硬件要等到下一个更新事件 UEV 才把它搬进真正的比较寄存器。所以当前周期正在用的 CCR 不会被你中途改写打断，波形永远是完整的。CubeMX 里对应 Output Compare Preload = Enable 和 Auto-Reload Preload = Enable，这两项在 FOC 工程里必须打开。

8.2.3 死区：为什么是 40

同一桥臂上下管绝不能同时导通，否则母线直接短路。但 MOSFET 关断有延迟（$t_{d(off)}$ 通常比导通延迟大），所以互补通道必须插入一段「两个都关断」的时间，即死区。DTG 寄存器值的换算：

$$t_{dead}=DTG\times t_{DTS},\qquad t_{DTS}=\frac{1}{f_{CK\_CNT}}\times 2^{CKD[1:0]}$$

本项目 ClockDivision = DIV2，即 $t_{DTS}=2/170\ \text{MHz}=11.76\ \text{ns}$；DeadTime = 40：

$$t_{dead}=40\times 11.76\ \text{ns}\approx 470\ \text{ns}$$

470 ns 是「够用且不算浪费」的常用值：一般 MOSFET + 栅极驱动的总关断延迟在 100~300 ns，留一倍余量即可。死区不是越大越好——死区时间越长，输出电压损失越大，低速时表现为转矩脉动和波形畸变，这就是为什么高端方案要做死区补偿（按电流极性补一个 $t_{dead}\cdot\mathrm{sign}(i)$ 的电压量）。

为什么额外设 CKD = DIV2？它把死区的时间分辨率从 5.88 ns 降到 11.76 ns，换来的是 DTG 的可用范围翻倍，同时给采样/滤波一点抗抖。如果你要的是 50 ns 级别的精细死区，就把 CKD 改成 DIV1。

8.2.4 重复计数器 RCR = 1：把 UEV 从 40 kHz 拉回 20 kHz

这是最容易被忽略、也最容易被误解的一个参数。在中心对齐模式下，重复计数器在每个上溢和每个下溢都递减一次（见 RM0440）——也就是说一个 PWM 周期内会递减两次。所以：

RCR 寄存器值更新事件（UEV）频率说明
040 kHz每个上溢/下溢都产生 UEV
1（本项目）20 kHz两次递减才溢出，UEV 与 PWM 周期对齐 ✔
213.33 kHz每 1.5 个 PWM 周期一次（不常用）

本项目的 TRGO2 = Update，任何挂在 TRGO2 上的外设（或者你自己在更新中断里做的事）都会受它影响。设成 1 保证「一个 PWM 周期、一次更新」这个直觉成立。另外提醒一句：奇数 RCR 时 UEV 相对三角波的相位取决于你写 RCR 与启动计数器的先后顺序；想要确定的相位，就在启动前把 TIM1->CNT = 0 和 EGR 的 UG 位安排清楚。

8.2.5 CH4：一个没有引脚的通道，却是整个系统的扳机

关键配置：CH4 = PWM Generation CH4、PWM Mode 2、Pulse (CCR4) = ARR - 3 = 4246、TIM1 TRGO = OC4REF。而 PE8~PE13 六个引脚只分配给了 CH1/CH1N、CH2/CH2N、CH3/CH3N，CH4 没有任何 GPIO。

为什么是"PWM 模式 2 + CCR4 = ARR−3"？把两个事实叠起来看：

  • PWM 模式 2 在中心对齐下的输出是关于三角波顶点对称的窄脉冲（模式 1 则关于谷点对称）。
  • 脉冲宽度 $=2\times(ARR-CCR4)=2\times 3=6$ 个计数周期，中心正好压在 CNT = ARR 上。

于是得到一个精确的、关于"三相下管全通时刻"居中的触发脉冲。它的上升沿出现在顶点前 3 个计数周期（约 17.6 ns），ADC 被配置为上升沿触发注入转换，转换完成后产生 JEOC 中断 —— 电流环就在那里开始跑。

为什么是 3，不是 0？留一点点提前量，让 ADC 的采样保持窗口（本项目 2.5 cycles @ 42.5 MHz ≈ 59 ns）完整落在下管导通区间内，同时避开三角波顶点处可能的计数抖动。这个数字是工程余量，不是理论常数；如果你改了采样周期或 PWM 频率，记得重新核对。

最后一点：CH4 必须 HAL_TIM_PWM_Start() 但不接引脚。启动代码里这一行是有意的：

TIM1->CCR4 = TIM1->ARR - 3;          /* 触发点：三角波顶点前 3 个计数 */
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_4);  /* 只启动 OC4REF，无物理输出 */
HAL_TIMEx_PWMN_Start(&htim1, TIM_CHANNEL_1);  /* CH1N/2N/3N 互补输出 */

8.2.6 上管下管到底怎么控制：为什么 CNT = ARR 时上管一定关断

这是把"寄存器数值"翻译成"功率管动作"的关键一步。先看硬件：每一相是一个半桥——上管接母线正（V+），下管接母线负（经分流电阻到 GND），中点接电机相线。上管由 CHx 驱动，下管由 CHxN 驱动，两者互补，硬件用死区保证它们不会同时导通。

桥臂状态CHx（上管栅极）CHxN（下管栅极）电流路径分流电阻上有电流吗
上管导通有效电平（高）无效（低）母线 V+ → 上管 → 电机相线没有（电流不走下桥臂）
死区低低电机相线 → 下管体二极管续流续流电流，不能采
下管导通无效（低）有效（高）电机相线 → 下管 → 分流电阻 → GND有，且就等于该相相电流

由此得到对采样至关重要的一条结论：只有下管导通的时候，分流电阻里流的才是该相的相电流。上管导通时电流从母线正进来直接进电机，压根不经过下桥臂那个电阻。所以采样时刻必须挑在下管导通的区间内 —— 这不是"讲究"，是硬约束。

那么"下管什么时候导通"由什么决定？回到 PWM 模式 1（CNT < CCR → 输出有效电平）加互补输出，一共只有两种情形：

$$CNT < CCR \ \Rightarrow\ CHx = 1,\ CHxN = 0$$ $$CNT > CCR \ \Rightarrow\ CHx = 0,\ CHxN = 1$$

翻译成人话：CNT 小于 CCR 时上管导通、下管关断；CNT 大于 CCR 时上管关断、下管导通。两种情形之间夹着死区（两边都关）。没有第三种可能。

现在把 CNT = ARR 代进去。ARR 是整个计数范围的最大值，而任何一相的 CCR 都满足 $CCR \le ARR$（占空比不可能超过 100%）。所以三角波顶点处：

$$CNT = ARR \ \ge\ CCR_U,\ CCR_V,\ CCR_W$$

三相无一例外全部满足"CNT > CCR"——于是三相上管同时关断、下管同时导通。这就是"CNT = ARR 时上管关闭"的全部原因：不是什么额外的逻辑，只是"在最高点，计数值必然大于所有比较值"这一件事的直接推论。

那如果某相占空比 = 100% 呢？此时 $CCR = ARR$，顶点处 $CNT = CCR$ 正好相等，按模式 1 的严格小于判定，输出仍然无效 → 上管关、下管通，结论不变。实际工程里 SVPWM 做过零序注入后会主动把最大占空比限幅（比如 96%~98%），一是给 bootstrap 自举电容留出充电时间（上管长时间导通则下管无导通窗口，自举电容充不上电，高端驱动会欠压），二是保证顶点附近一定存在一个所有相都在下管的干净采样窗口。

拖动下面的时间轴，对照三相桥的开关状态看一个完整周期：

图 8-3：三相逆变桥在一个 PWM 周期内的开关状态时间轴。上半部分是电路拓扑，绿色代表该管正在导通、暗色代表关断，可以直观看到"电流此刻从哪条路走"；下半部分是 U/V/W 三相的开关时序。注意两条规律：① 每相上下管永远互补，不会同时亮；② 只有在中间（CNT = ARR，三角波顶点）的绿色采样窗口里，三相下管才同时导通——这就是全周期唯一一个可以一次采全三相电流的时刻。占空比越大的相，上管导通的时间越宽（关于顶点对称），这是中心对齐模式的特征。

把图 8-1 和图 8-3 叠起来看，整个"扳机"设计就完全说得通了：

  1. CNT 爬到 ARR → 三相上管自然全部关断、下管全部导通；
  2. 分流电阻上此刻流过真实相电流，且这是全周期最宽的一段干净窗口（因为关于顶点对称）；
  3. CH4 的 CCR4 = ARR−3 + PWM 模式 2，正好在这段窗口的中心拉出一个 6 个计数宽的脉冲；
  4. 脉冲上升沿触发 ADC12 双注入同步转换 → 转完产生 JEOC → 电流环开跑。

四步环环相扣，没有任何一步是靠"猜时间"实现的：CNT 是硬件数的、CCR 是 SVPWM 算的、触发是硬件连的（TRGO → ADC 外部触发）、中断是转换完成自动来的。这也解释了为什么 FOC 工程里几乎见不到"在定时器中断里读 ADC"的写法 —— 那条路每一步都要软件对齐，抖动不可控。

一个常见的误解：有人以为"上管导通时也能采到电流"。不行 —— 上管导通时该相被接到母线正，电流从母线来，不经过下桥臂的分流电阻，采样值是 0 或者上一相的续流残留。三电阻方案之所以比母线单电阻方案友好，正是因为它有三个独立的下桥臂电阻，只要各自下管导通就能读；但它依然要遵守"下管导通才有效"这条铁律，所以采样点仍然必须钉在顶点。

8.3.1 各级参数怎么来的

  • 分流电阻 5 mΩ：10 A 时耗散 $I^2R=0.5\ \text{W}$，压降 50 mV。选值是在「压降够大好测」和「功耗/发热小」之间折中，一般让满量程压降落在 50~100 mV。
  • 运放增益 30×：$50\ \text{mV}\times 30=1.5\ \text{V}$，加上 1.65 V 偏置后输出在 0.15~3.15 V，正好铺满 ADC 输入范围而不削顶。
  • 偏置 1.65 V：相电流是交流（有正有负），而 ADC 只能测正电压。把零电流抬到 $V_{REF}/2$，负半周才有地方放。
  • 分辨率：$\dfrac{3300\ \text{mV}}{4096}\times\dfrac{1}{30}\times\dfrac{1}{5\ \text{m}\Omega}\approx 5.37\ \text{mA/LSB}$。也就是说1 个 ADC 码 = 5.37 mA，10 A 量程下理论分辨率约 11 bit。

换算公式（工程里的写法）：

$$I_{abc}=\left(V_{offset}-ADC_{raw}\right)\times\frac{3300}{4095}\times\frac{1}{1000}\times\frac{1}{30}\times\frac{1}{0.005}\ \ \text{[A]}$$

代码里对应这段（分子在前、零点在前，注意符号）：

/* 零点在启动时校准：PWM 全关、电机静止，采 500 次求平均 */
moto->Ia = (moto->Ia_zero - (float)ADC1->JDR1) * 3.3f / 4095.0f / 30.0f / 0.005f;
moto->Ib = (moto->Ib_zero - (float)ADC2->JDR1) * 3.3f / 4095.0f / 30.0f / 0.005f;
moto->Ic = (moto->Ic_zero - (float)ADC1->JDR2) * 3.3f / 4095.0f / 30.0f / 0.005f;

8.3.2 双 ADC 注入同步：为什么要 ADC1 + ADC2 一起上

相电流必须同时采样。如果用同一个 ADC 的注入组按 rank1→rank2→rank3 顺序转，三次转换之间隔着采样+转换时间（每个约 0.5 µs），三相读数就不是同一时刻的值，$i_a+i_b+i_c=0$ 不再成立，Clarke 变换会引入误差，电流环有静差甚至抖动。

G4 的解法是 ADC1 主 + ADC2 从的双模式注入同步（ADC_DUALMODE_INJECSIMULT）：同一个触发信号同时启动两个 ADC 的注入组，各自独立转换，rank 相同的通道严格同时采样：

ADC角色Rank 1Rank 2结果寄存器
ADC1主（触发源 = TIM1 TRGO）CH3 → PA2 = $i_a$CH12 → PB1 = $i_c$ADC1->JDR1 / JDR2
ADC2从（跟随 ADC1）CH3 → PA6 = $i_b$CH1 → PA0 = $V_{bus}$ADC2->JDR1 / JDR2

要点：

  • 只用 ADC1 开中断。两个 ADC 都会置 JEOC，但从机的也会触发同一个中断向量，所以回调里必须过滤：if (hadc->Instance == hadc1.Instance) { ... }。
  • 启动顺序是 HAL_ADCEx_InjectedStart(&hadc2) 先、HAL_ADCEx_InjectedStart_IT(&hadc1) 后，先开从再开主。
  • 采样时间 2.5 cycles 是很激进的设置（42.5 MHz ADC 时钟下约 59 ns）。它依赖运放输出阻抗足够低；如果你的板子采样噪声大，第一件事就是把它调大到 6.5 / 12.5 cycles，代价是转换延迟变长，要回头核对 8.2.5 里那 3 个计数的提前量够不够。
  • 上电先做自校准：HAL_ADCEx_Calibration_Start() 消除 ADC 本身的偏移，之后再做电流零点校准（PWM 关闭、静止、500 次平均）。

8.4 三环调度：一个定时器，三个节拍

电流环 20 kHz 是硬性要求（由功率级和电流纹波决定），但速度环和位置环没必要跑这么快——它们的对象时间常数比电流环大一到两个数量级。工程上的做法是软件分频：在 20 kHz 的 ADC 中断里用计数器分频，不占用额外定时器。拖动下面的时间轴看三个环的节拍关系：

图 8-5：单一定时器 + 软件分频的三环调度。电流环每个 ADC 中断都跑（20 kHz）；速度环每 5 次跑一次（4 kHz）；位置环每 3 个速度环节拍跑一次（≈1.33 kHz）。分频比不是随便取的：速度环带宽通常是电流环的 1/5 ~ 1/10，位置环再降一档，这样每环之间留出足够的相位裕度，串级才不会互相打架。

典型实现（在 ADC 注入完成回调里）：

void HAL_ADCEx_InjectedConvCpltCallback(ADC_HandleTypeDef *hadc)
{
  if (hadc->Instance != ADC1) return;        /* 过滤 ADC2 从机的 JEOC */
  GPIOA->BSRR = GPIO_PIN_4;                  /* PA4 拉高：示波器测中断耗时 */

  Moto_Handler();                            /* Clarke → Park → 电流环 PID */

  if (++spd_div >= 5) {                      /* 20k / 5 = 4 kHz */
    spd_div = 0;
    Speed_Loop();                            /* 速度环 PID → Iq_ref */
    if (++pos_div >= 3) {                    /* 4k / 3 ≈ 1.33 kHz */
      pos_div = 0;
      Position_Loop();                       /* 位置环 PID → Spd_ref */
    }
  }
  GPIOA->BRR = GPIO_PIN_4;                   /* PA4 拉低 */
}
PA4 那两行一定要留着。它是整个 FOC 调试中最便宜也最有效的工具：示波器看 PA4 高电平宽度 = 电流环单次执行时间，看周期 = 20 kHz 是否稳定，看抖动 = 有没有被别的中断打断。PA4 周期不是 50 µs 或高电平超过 25 µs，就说明有问题。

8.5 角度从哪来：SPI 磁编码器

Park / iPark 两个变换都需要电角度 $\theta_e$。本项目用 MT6701 这类 SPI 接口的磁编码器，14 bit 单圈绝对值，配置要点：

  • SPI 全双工主机、CPOL=Low/CPHA=1Edge（Mode 0）或按手册，8/16 位帧，波特率分频给到几 MHz 即可（编码器更新率才是瓶颈）。
  • 片选必须软件控制（GPIO 输出而非硬件 NSS），因为要精确控制帧边界；读角度通常是「发 2 字节 dummy，收 2 字节角度」。
  • 14 bit → 角度：$\theta_m = \frac{raw}{16384}\times 2\pi$。极对数 $p$ 则电角度 $\theta_e = p\cdot\theta_m - \theta_{offset}$。
  • 零点标定：给 $U_d=1, U_q=0$（$\sin\theta=0,\ \cos\theta=1$）直流锁定 1~1.5 s，把转子强吸到电角度 0，读此时的编码器原始值即为 offset。这是 v2.0 里 Moto_Encoder_Calib() 的做法。
  • 角度外插：编码器更新率通常低于 20 kHz，在两个采样点之间用 $\theta \mathrel{+}= \omega \cdot T_s$ 做一阶外插，能明显降低高速时的角度滞后。

8.7 启动顺序：一个都不能错

FOC 工程的上电顺序是有讲究的——先让测量链路准备好，再发波，否则第一拍就采到垃圾数据。两版工程的顺序完全一致：

/* 1. ADC 自校准 */
HAL_ADCEx_Calibration_Start(&hadc1, ADC_SINGLE_ENDED);
HAL_ADCEx_Calibration_Start(&hadc2, ADC_SINGLE_ENDED);
/* 2. 运放自校准 + 启动（Standalone 模式也要） */
HAL_OPAMP_SelfCalibrate(&hopamp1); HAL_OPAMP_Start(&hopamp1);  /* 2、3 同理 */
/* 3. 占空比清零，避免上电瞬间直通 */
TIM1->CCR1 = TIM1->CCR2 = TIM1->CCR3 = 0;
/* 4. 启动 PWM：先 CH1/2/3，再互补 CHxN */
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1); /* 2、3 同理 */
HAL_TIMEx_PWMN_Start(&htim1, TIM_CHANNEL_1);
/* 5. 装填扳机并启动 CH4（无引脚） */
TIM1->CCR4 = TIM1->ARR - 3;
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_4);
/* 6. 计数器归零，保证第一次触发相位确定 */
TIM1->CNT = 0;
/* 7. ADC 注入：先开从机（不中断），再开主机（中断） */
HAL_ADCEx_InjectedStart(&hadc2);
HAL_ADCEx_InjectedStart_IT(&hadc1);
/* 8. 最后启动定时器基准 → 电流环开始跑 */
HAL_TIM_Base_Start(&htim1);
while (State == moto_Calib) { /* 阻塞等待零点标定完成 */ }
关于第 3 步：上电瞬间 GPIO 可能是浮空态，CCR 寄存器也可能有残留值。PWM 启动前把所有 CCR 清零，是防止"上电即满占空比炸管"最省事的一招。同理，换相/停机时也要先关输出再停定时器。

8.8 USB CDC：48 MHz 时钟这道题怎么解

G4 上 USB FS 的引脚是唯一的（PA11/PA12，无备用映射），FDCAN 改到 PB8/PB9（AF9）后两者互不冲突。真正的难点是时钟：USB 要求 48 MHz ±0.25%，而

$$HSE\ 24\,\text{MHz}\xrightarrow{/M=6}4\,\text{MHz}\xrightarrow{\times N=85}VCO=340\,\text{MHz}\xrightarrow{R=/2}SYSCLK=170\,\text{MHz}$$ $$PLLQ=\frac{340}{48}=7.083\quad\Rightarrow\quad \frac{340}{7}=48.57\ \text{MHz}$$

相对 48 MHz 偏差 +1.19%，而 USB 规范要求 ±0.25% —— 超了近 5 倍，此路不通。想救就得改 VCO：$48\times7=336\ \text{MHz}$，可此时 $R=336/170=1.976$ 又不是整数。

结论：24 MHz HSE + 170 MHz 主频这个组合下，PLLQ 给不出合格的 48 MHz，必须用 HSI48 + CRS。HSI48 出厂精度约 ±1.5%，靠 CRS 用主机每 1 ms 的 SOF 包自动微调。而 CubeMX 只会生成 USB 时钟源选择和 NVIC，不会生成 HSI48 使能和 CRS 配置，这两段必须手写（放在 usb_device.c 的 USER CODE BEGIN USB_Device_Init_PreTreatment 块里，否则重生成会被冲掉）：

RCC_OscInitTypeDef o = {0};
o.OscillatorType = RCC_OSCILLATORTYPE_HSI48;
o.PLL.PLLState   = RCC_PLL_NONE;
o.HSI48State     = RCC_HSI48_ON;
HAL_RCC_OscConfig(&o);

__HAL_RCC_CRS_CLK_ENABLE();
RCC_CRSInitTypeDef crs = {0};
crs.Prescaler   = RCC_CRS_SYNC_DIV1;
crs.Source      = RCC_CRS_SYNC_SOURCE_USB;                          /* SOF = 1 kHz */
crs.Polarity    = RCC_CRS_SYNC_POLARITY_RISING;
crs.ReloadValue = __HAL_RCC_CRS_RELOADVALUE_CALCULATE(48000000, 1000); /* = 47999，别漏 */
crs.ErrorLimitValue = RCC_CRS_ERRORLIMIT_DEFAULT;
crs.HSI48CalibrationValue = RCC_CRS_HSI48CALIBRATION_DEFAULT;
HAL_RCCEx_CRSConfig(&crs);
坑位提醒：ReloadValue 很容易被漏掉（AI 生成的 v3.0 就只写了 Source，其余为 0）。ReloadValue=0 时 CRS 计数器每个 SOF 就溢出一次，会持续报错，HSI48 实际上没被校准——表现是短时间能枚举，跑几分钟或温度一变就掉线。判据：连发 1 分钟长包不掉线。

收发侧的两个纪律：

  • 接收：CDC_Receive_FS() 里只做「塞进环形缓冲 + 重新挂 USBD_CDC_ReceivePacket()」，解析放主循环。中断里不要做浮点、不要 printf。
  • 发送：连续发送前必须查 USBD_CDC_GetTxState()，否则上一次没发完就被覆盖，直接丢包。

8.9 面试视角：外设与时序

Q：FOC 的电流环为什么放在 ADC 中断，不放在定时器更新中断？
因为更新事件的时刻与"电流已稳定可采样"的时刻无关，而 ADC 注入由 TIM1 的 OC4REF 精确触发在三相下管全通的窗口中心，采样→转换→中断→计算→写 CCR 是一条延迟恒定的因果链。放更新中断里则采样点要另外对齐，容易采到开关噪声。
Q：中心对齐模式下，ARR 怎么算？为什么是 2×(ARR+1)？
计数器上数到 ARR 再下数到 0，一个 PWM 周期含 2×ARR 个计数，所以 f = f_CK_CNT / (2(ARR+1))。170 MHz / 20 kHz / 2 − 1 = 4249。
Q：重复计数器在中心对齐模式下的行为？
每个上溢和每个下溢都递减一次，即一个 PWM 周期递减两次。RCR=0 → UEV 是 PWM 频率的 2 倍；RCR=1 → UEV 与 PWM 同频。
Q：为什么不按顺序用单个 ADC 采三相？
顺序采样时三相不是同一时刻的值，i_a+i_b+i_c=0 不成立，Clarke 变换引入误差。用双 ADC 注入同步模式让 rank 相同的通道严格同时采样。
Q：死区时间怎么影响输出？怎么补偿？
死区使实际输出电压偏离指令，方向取决于相电流极性，低速时表现为波形畸变、转矩脉动、甚至"转不动"。补偿方法：按电流符号给占空比加/减 t_dead 对应的计数量（死区补偿），或做成电压前馈。
Q：怎么判断你的电流环真的跑在 20 kHz？
在中断入口/出口翻转一个 GPIO（如 PA4），示波器看周期是否为 50 µs、高电平宽度（= 单次执行时间）是否远小于 50 µs、抖动是否可控。这是最直接的体检手段。
